WPA Control Interface

The Wi-Fi Protected Access (WPA) control interface allows external programs to control the services that implement the WPA/IEEE 802.11i protocols and handle key negotiation, authentication, and roaming for Wi-Fi clients, and get status and event data from them.

The control interface is a C API that also works in C++ code. To use this API, your programs must link against the libwpactrl-ver.so library. This QNX SDP release uses version 2.9 of the WPA supplicant, so you must provide the -l wpactrl-2.9 option to qcc.

Note: This interface has been tested against wpa_supplicant and is known to work with this service, but should also work with hostapd (even though this isn't officially supported). For more information about these services, see the hostapd and wpa_supplicant references in the QNX OS Utilities Reference.

  • wpa_ctrl_attach()
    Register as an event monitor
  • wpa_ctrl_close()
    Close a control connection to the WPA control interface
  • wpa_ctrl_detach()
    Unregister as an event monitor
  • wpa_ctrl_get_fd()
    Get the file descriptor for the control connection
  • wpa_ctrl_open()
    Open a control connection to the WPA control interface
  • wpa_ctrl_pending()
    Check for pending event messages
  • wpa_ctrl_recv()
    Receive an event message
  • wpa_ctrl_request()
    Send a command request to the WPA control interface
  • wpa_ctrl_set_cmd_timeout()
    Set the timeout for all command requests
