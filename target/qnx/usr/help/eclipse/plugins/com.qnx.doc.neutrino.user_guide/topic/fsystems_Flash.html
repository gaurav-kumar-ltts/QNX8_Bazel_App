FFS3 filesystem

The Flash FileSystem version 3 (FFS3) drivers implement a POSIX-compatible filesystem on NOR flash memory devices. This filesystem is unique to QNX OS.

The drivers are standalone executables that contain both the flash filesystem code and the flash device code. There are versions of FFS3 drivers for different embedded systems hardware and PCMCIA memory cards. The naming convention for the drivers is devf-system, where system describes the embedded system. For information about these drivers, see the devf-* entries in the Utilities Reference.

Note: FFS3 filesystems don't include . and .. entries for the current and parent directories.

For information on creating and handling FFS3 filesystems, see:

  • mkefs and flashctl in the Utilities Reference
  • Filesystems in the System Architecture guide
  • Building Embedded Systems
