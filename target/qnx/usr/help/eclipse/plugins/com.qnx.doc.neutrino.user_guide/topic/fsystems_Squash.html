Linux Squash filesystem

The Linux Squash filesystem (squashfs) is a compressed read-only filesystem that allows you to compress data, inodes, and directories.

The fs-squash.so shared object provides access to Squash filesystems for QNX OS. The devb-* drivers automatically load fs-squash.so when mounting a Squash filesystem.
