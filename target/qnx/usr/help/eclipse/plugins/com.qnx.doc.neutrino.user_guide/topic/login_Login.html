Logging in

If your system is configured to do so, it prompts you for your user name and then your password.

The system does this by automatically starting the login utility.

Note: If you type an invalid user name, the system prompts you for the password anyway. This avoids giving clues to anyone who's trying to break into the system.

Text mode on an x86_64 machine could be on a physical console supplied by devc-con or devc-con-hid. On any other type of machine, you could be connecting to the target via a serial port or TCP/IP connection.
