Getting to Know the OS

Welcome to the QNX OS!

This section describes how the QNX OS compares to Unix and Microsoft Windows, from a user's (not a developer's) perspective. For more details about QNX OS's design and the philosophy behind it, see the System Architecture guide.

  • QNX OS compared with Unix
    If you're familiar with Unix-style operating systems, you'll feel right at home with QNX OS—many people even pronounce QNX to rhyme with Unix (some spell it out: Q-N-X).
  • QNX OS compared with Microsoft Windows
    QNX OS and Windows have different architectures, but the main difference between them from a user's perspective is how you invoke programs.
  • How QNX OS is unique
    The QNX OS consists of a microkernel (procnto) and various processes. Each process—even a device driver—runs in its own virtual memory space.
