input_class_e

Classes of input events

Synopsis:

#include <input/event_types.h>
typedef enum {
    INPUT_CLASS_MTOUCH = 1,
    INPUT_CLASS_KEYBOARD,
    INPUT_CLASS_MOUSE,
    INPUT_CLASS_MTOUCH_EXTERNAL
} input_class_e;

Data:

INPUT_CLASS_MTOUCH
A touch-related event on the touchscreen.
INPUT_CLASS_KEYBOARD
A key event on the virtual keyboard.
INPUT_CLASS_MOUSE
A mouse event using a connected mouse.
INPUT_CLASS_MTOUCH_EXTERNAL
A touch-related event on the touchscreen that's forwarded to Screen graphics subsystem.

Library:

libinputevents
