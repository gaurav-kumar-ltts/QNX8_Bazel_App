#include <input/mtouch_log.h>
#define mtouch_debug mtouch_log(_SLOG_DEBUG1, devname, format, ##args)

Print mtouch log information as SLOG_DEBUG1 severity.

This macro implements an mtouch_log() function with severity of SLOG_DEBUG. If NDEBUG is defined, the information is sent as a message to the system logger (slogger2). Otherwise, the log is simply directed to stderr. The mtouch_log() output format is: devname[DEBUG]: formatted argument list.
