contact_type_e

Types of contact for an INPUT_CLASS_MTOUCH event

Synopsis:

#include <input/event_types.h>
typedef enum {
    CONTACT_TYPE_FINGER = 0,
    CONTACT_TYPE_STYLUS = 1,
    CONTACT_TYPE_HOVERING = 2,
    CONTACT_TYPE_GLOVE = 3,
    CONTACT_TYPE_LARGE = 4
} contact_type_e;

Data:

CONTACT_TYPE_FINGER
Finger touch (default).
CONTACT_TYPE_STYLUS
Stylus touch.
CONTACT_TYPE_HOVERING
Hovering finger.
CONTACT_TYPE_GLOVE
Glove touch.
CONTACT_TYPE_LARGE
Large object.
