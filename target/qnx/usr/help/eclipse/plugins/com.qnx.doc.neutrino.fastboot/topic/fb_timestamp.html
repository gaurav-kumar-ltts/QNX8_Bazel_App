Using timestamp to measure startup times

You can use the timestamp command to log startup times at specific points during startup.

By default, the command creates a timestamp.log file, which contains time measurements from board reset to a particular system event (the time from board reset varies depending on your platform).

Note: Although this log is purely for reference purposes, you can get important information from it that can help you tune your system startup.

For more information, see timestamp in the Utilities Reference.
