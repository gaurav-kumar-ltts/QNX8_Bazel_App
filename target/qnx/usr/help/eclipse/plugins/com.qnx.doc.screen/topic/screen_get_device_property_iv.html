screen_get_device_property_iv()

Retrieve the current value of the specified device property of type integer

Synopsis:

#include <screen/screen.h>
int screen_get_device_property_iv(screen_device_t dev,
                                  int pname,
                                  int *param)

Arguments:

dev
The handle of the device whose property is being queried.
pname
The name of the property whose value is being queried. The properties available for query are of type Screen property types.
param
A pointer to a buffer where this function stores the retrieved value(s). This buffer must be of type int. The buffer may be a single integer or an array of integers, depending on the property being retrieved.

Library:

libscreen

Description:

Function Type: Flushing Execution

This function stores the current value of a device property in a user-provided buffer.

The values of the following properties can be retrieved using this function:
  • SCREEN_PROPERTY_ACCELERATION (for SCREEN_EVENT_GAMEPAD, SCREEN_EVENT_JOG, SCREEN_EVENT_JOYSTICK, and SCREEN_EVENT_POINTER only)
  • SCREEN_PROPERTY_ANALOG0 (for SCREEN_EVENT_GAMEPAD and SCREEN_EVENT_JOYSTICK only)
  • SCREEN_PROPERTY_ANALOG1 (for SCREEN_EVENT_GAMEPAD and SCREEN_EVENT_JOYSTICK only)
  • SCREEN_PROPERTY_ANALOG_COUNT (for SCREEN_EVENT_GAMEPAD and SCREEN_EVENT_JOYSTICK only)
  • SCREEN_PROPERTY_BALLISTIC_COEFFICIENTS (for SCREEN_EVENT_MTOUCH_TOUCH only)
  • SCREEN_PROPERTY_BUTTONS (for all events except SCREEN_EVENT_KEYBOARD)
  • SCREEN_PROPERTY_BUTTON_COUNT
  • SCREEN_PROPERTY_BUTTON_MAP (for SCREEN_EVENT_GAMEPAD, SCREEN_EVENT_JOG, SCREEN_EVENT_JOYSTICK, and SCREEN_EVENT_POINTER only)
  • SCREEN_PROPERTY_DPI (for SCREEN_EVENT_GAMEPAD, SCREEN_EVENT_JOG, SCREEN_EVENT_JOYSTICK, and SCREEN_EVENT_POINTER only)
  • SCREEN_PROPERTY_FLOATING (for SCREEN_EVENT_POINTER only)
  • SCREEN_PROPERTY_GESTURE_PARAMETERS (for SCREEN_EVENT_GAMEPAD, SCREEN_EVENT_JOG, SCREEN_EVENT_JOYSTICK, and SCREEN_EVENT_MTOUCH_TOUCH only)
  • SCREEN_PROPERTY_ID [1]
  • SCREEN_PROPERTY_IDLE_STATE
  • SCREEN_PROPERTY_KEYMAP_PAGE
  • SCREEN_PROPERTY_MAXIMUM_TOUCH_ID (for SCREEN_EVENT_MTOUCH_TOUCH only)
  • SCREEN_PROPERTY_METRIC_COUNT [1]
  • SCREEN_PROPERTY_MODE (for SCREEN_EVENT_GAMEPAD, SCREEN_EVENT_JOG, SCREEN_EVENT_JOYSTICK, and SCREEN_EVENT_MTOUCH_TOUCH only)
  • SCREEN_PROPERTY_MODIFIERS
  • SCREEN_PROPERTY_OWNER_PID [1]
  • SCREEN_PROPERTY_PERMISSIONS
  • SCREEN_PROPERTY_PHYSICAL_SIZE (for SCREEN_EVENT_MTOUCH_TOUCH only)
  • SCREEN_PROPERTY_POWER_MODE
  • SCREEN_PROPERTY_PRODUCT
  • SCREEN_PROPERTY_SCALE_FACTOR [1]
  • SCREEN_PROPERTY_SIZE (for SCREEN_EVENT_GAMEPAD, SCREEN_EVENT_JOG, SCREEN_EVENT_JOYSTICK, SCREEN_EVENT_MTOUCH_TOUCH, and SCREEN_EVENT_POINTER only)
  • SCREEN_PROPERTY_SEQUENCE_ID
  • SCREEN_PROPERTY_SPEED (for SCREEN_EVENT_GAMEPAD, SCREEN_EVENT_JOG, SCREEN_EVENT_JOYSTICK, and SCREEN_EVENT_POINTER only)
  • SCREEN_PROPERTY_STATUS
  • SCREEN_PROPERTY_STICKY_MODIFIERS
  • SCREEN_PROPERTY_TRANSFORM (for SCREEN_EVENT_MTOUCH_TOUCH only)
  • SCREEN_PROPERTY_TYPE
  • SCREEN_PROPERTY_VENDOR

Note [1]: When retrieving this property, the function type is Immediate Execution.

Returns:

0 if successful, or -1 if an error occurred (errno is set; refer to errno.h for more details).
