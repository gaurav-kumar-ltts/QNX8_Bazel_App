screen_get_device_property_fv()

Retrieve the current value of the specified device property of type float

Synopsis:

#include <screen/screen.h>
int screen_get_device_property_fv(screen_device_t dev, int pname, float *param)

Arguments:

dev
The handle of the device whose property is being queried.
pname
The name of the property whose value is being queried. The properties available for query are of type Screen property types.
param
A pointer to a buffer where this function stores the retrieved value(s). This buffer must be of type float.

Library:

libscreen

Description:

Function Type: Flushing Execution

This function stores the current value of a device property in a user-provided buffer.

The values of the following properties can be retrieved using this function:
  • SCREEN_PROPERTY_BALLISTIC_COEFFICIENTS (for SCREEN_EVENT_MTOUCH_TOUCH only)
  • SCREEN_PROPERTY_TRANSFORM (for SCREEN_EVENT_MTOUCH_TOUCH only)

Note [1]: When retrieving this property, the function type is Immediate Execution.

Returns:

0 if successful, or -1 if an error occurred (errno is set; refer to errno.h for more details).
