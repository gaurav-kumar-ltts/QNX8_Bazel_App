Screen device types

Types of devices.

Synopsis:

#include <screen/screen.h>
 

 enum {
      ...
      SCREEN_EVENT_JOG = 5,
      SCREEN_EVENT_POINTER = 6,
      SCREEN_EVENT_KEYBOARD = 7,
      ...
      SCREEN_EVENT_GAMEPAD = 14,
      SCREEN_EVENT_JOYSTICK = 15,
      ...
      SCREEN_EVENT_GESTURE = 18,
      ...
      SCREEN_EVENT_MTOUCH_TOUCH = 100,
};

Data:

SCREEN_EVENT_JOG
Represents a device with a jog input, such as a jog dial or jog wheel.
SCREEN_EVENT_POINTER
Represents a pointer device.
SCREEN_EVENT_KEYBOARD
Represents a keyboard.
SCREEN_EVENT_GAMEPAD
Represents a gamepad.
SCREEN_EVENT_JOYSTICK
Represents a joystick.
SCREEN_EVENT_GESTURE
Represents gesture device.
SCREEN_EVENT_MTOUCH_TOUCH
Represents a multi-touch device.

Library:

libscreen

Description:

Device types are a subset of the enumeration, Screen event types .
