screen_get_window_property_fv()

Retrieve the current value of the specified window property of type float

Synopsis:

#include <screen/screen.h>
int screen_get_window_property_fv(screen_window_t win, int pname, float *param)

Arguments:

win
The handle of the window whose property is being queried.
pname
The name of the property whose value is being queried. The properties available for querying are of type Screen property types.
param
A pointer to a buffer where this function stores the retrieved value(s). This buffer must be of type float.

Library:

libscreen

Description:

Function Type: Flushing Execution

This function retrieves the value(s) of a window property and stores them in a user-provided buffer. The values of the following properties can be queried using this function:
  • SCREEN_PROPERTY_BRIGHTNESS
  • SCREEN_PROPERTY_CONTRAST
  • SCREEN_PROPERTY_HUE
  • SCREEN_PROPERTY_SATURATION
  • SCREEN_PROPERTY_TRANSFORM

Returns:

0 if successful, or -1 if an error occurred (errno is set; refer to errno.h for more details).
