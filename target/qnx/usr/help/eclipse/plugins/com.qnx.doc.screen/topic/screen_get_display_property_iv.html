screen_get_display_property_iv()

Retrieve the current value of the specified display property of type integer

Synopsis:

#include <screen/screen.h>
int screen_get_display_property_iv(screen_display_t disp,
                                   int pname,
                                   int *param)

Arguments:

disp
The handle of the display whose property is being queried.
pname
The name of the property whose value is being queried. The properties available for query are of type Screen property types.
param
A pointer to a buffer where this function stores the retrieved value(s). This buffer must be of type int. The buffer may be a single integer or an array of integers, depending on the property being retrieved.

Library:

libscreen

Description:

Function Type: Flushing Execution

This function stores the current value of a display property in a user-provided buffer.

The values of the following properties can be retrieved using this function:
  • SCREEN_PROPERTY_ATTACHED
  • SCREEN_PROPERTY_BLUE_GAMMA_CURVE [2]
  • SCREEN_PROPERTY_BRIGHTNESS
  • SCREEN_PROPERTY_CBABC_MODE
  • SCREEN_PROPERTY_CHROMATICITY_COORDS
  • SCREEN_PROPERTY_CONTRAST
  • SCREEN_PROPERTY_DETACHABLE
  • SCREEN_PROPERTY_DPI
  • SCREEN_PROPERTY_FOCUS
  • SCREEN_PROPERTY_FORMATS
  • SCREEN_PROPERTY_FORMAT_COUNT
  • SCREEN_PROPERTY_GAMMA [2]
  • SCREEN_PROPERTY_GREEN_GAMMA_CURVE [2]
  • SCREEN_PROPERTY_HUE
  • SCREEN_PROPERTY_ID [1]
  • SCREEN_PROPERTY_IDLE_STATE
  • SCREEN_PROPERTY_INTENSITY
  • SCREEN_PROPERTY_KEEP_AWAKES
  • SCREEN_PROPERTY_METRIC_COUNT [1]
  • SCREEN_PROPERTY_MIRROR_MODE
  • SCREEN_PROPERTY_MODE_COUNT
  • SCREEN_PROPERTY_NATIVE_RESOLUTION
  • SCREEN_PROPERTY_OWNER_PID [1]
  • SCREEN_PROPERTY_PERMISSIONS
  • SCREEN_PROPERTY_PHYSICAL_SIZE
  • SCREEN_PROPERTY_POSITION
  • SCREEN_PROPERTY_POWER_MODE
  • SCREEN_PROPERTY_PROTECTION_ENABLE
  • SCREEN_PROPERTY_RED_GAMMA_CURVE [2]
  • SCREEN_PROPERTY_ROTATION
  • SCREEN_PROPERTY_SATURATION
  • SCREEN_PROPERTY_SCALE_FACTOR [1]
  • SCREEN_PROPERTY_SEQUENCE_ID
  • SCREEN_PROPERTY_SIZE
  • SCREEN_PROPERTY_SOURCE_SIZE
  • SCREEN_PROPERTY_TECHNOLOGY
  • SCREEN_PROPERTY_TRANSPARENCY
  • SCREEN_PROPERTY_TYPE
  • SCREEN_PROPERTY_VIEWPORT_POSITION
  • SCREEN_PROPERTY_VIEWPORT_SIZE
  • SCREEN_PROPERTY_WINDOW_MANAGER_ID

Note [1]: When retrieving this property, the function type is Immediate Execution.

Note [2]: You must be working within a privileged context of type SCREEN_DISPLAY_MANAGER_CONTEXT to be able get set this property.

Returns:

0 if successful, or -1 if an error occurred (errno is set; refer to errno.h for more details).
