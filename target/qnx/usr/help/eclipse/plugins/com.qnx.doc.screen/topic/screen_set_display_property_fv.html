screen_set_display_property_fv()

Set the value of the specified display property of type float

Synopsis:

#include <screen/screen.h>
int screen_set_display_property_fv(screen_display_t disp, int pname, const float *param)

Arguments:

disp
The handle of the display whose property is to be set.
pname
The name of the property whose value is being set. The properties that you can set are of type Screen property types.
param
A pointer to a buffer containing the new value(s). This buffer must be of type float.

Library:

libscreen

Description:

Function Type: Delayed Execution

This function sets the value of a display property from a user-provided buffer. Typically, you must be working within a privileged context of type SCREEN_DISPLAY_MANAGER_CONTEXT to be able to set display-related properties.

You can use this function to set the value of the following properties:
  • SCREEN_PROPERTY_BRIGHTNESS
  • SCREEN_PROPERTY_CONTRAST
  • SCREEN_PROPERTY_GAMMA [1]
  • SCREEN_PROPERTY_HUE
  • SCREEN_PROPERTY_SATURATION

Note [1]: You must be working within a privileged context of type SCREEN_DISPLAY_MANAGER_CONTEXT to be able get set this property.

Returns:

0 if successful, or -1 if an error occurred (errno is set; refer to errno.h for more details).
