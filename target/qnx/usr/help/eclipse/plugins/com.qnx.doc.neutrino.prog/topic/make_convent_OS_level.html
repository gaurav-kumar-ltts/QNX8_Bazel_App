OS level

If you were building products to run on multiple operating systems, you'd include an OS-level directory structure. This would serve as a branchpoint for OS-specific subdirectories.

In our factory-floor example, the gui section might be built for both QNX 4 and QNX OS, whereas the other sections might be built just for QNX OS.

If no OS level is detected, QNX OS is assumed.
