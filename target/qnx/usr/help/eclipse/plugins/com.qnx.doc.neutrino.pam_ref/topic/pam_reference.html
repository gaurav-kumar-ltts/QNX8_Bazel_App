PAM Modules

Use these authentication modules to identify methods of authentication for your system to use. Each module description contains information about its options and service categories.

Note: For more information on how to configure the authentication policies that support these modules, see the System Security Guide.
For information about: See:
Rejecting requests pam_deny
Displaying a message pam_echo
Running a command pam_exec
Considering group membership pam_group
Accepting requests pam_permit
Legacy behavior pam_qnx
Authenticating the superuser pam_rootok
Type switching under a QNX security policy pam_secpol
Self authenticating pam_self
  • pam_deny
    Deny the authentication request.
  • pam_echo
    Displays a message
  • pam_exec
    Execute a command
  • pam_group
    Consider group membership.
  • pam_permit
    Allow the authentication request.
  • pam_qnx
    Legacy behavior (comparable to previous versions of QNX).
  • pam_rootok
    Check for UID 0.
  • pam_secpol
    Determines the type that should be associated with the user and switches to it if a security policy is loaded.
  • pam_self
    Self-authentication service.
