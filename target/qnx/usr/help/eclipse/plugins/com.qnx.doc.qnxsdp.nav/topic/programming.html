Programming

These guides explain how to develop programs for the QNX OS. Before trying to write programs, if you're new to the OS, you should read the Quickstart Guide; if you want to adapt programs developed with an earlier QNX SDP version to work with the latest version, read Migrating to QNX OS 8.0. You can then consult the guides listed below for your development work.

Getting Started with the QNX OS

This book, by Rob Krten and updated by BlackBerry QNX, will help you design and develop robust realtime systems—from tiny embedded control applications to large network-distributed systems—using the QNX OS.

Programmer's Guide

Tells you how to get started writing programs, and explains how to manage processes, handle interrupts, work with memory, and more.

Writing a Resource Manager

Explains how to write a resource manager, a process that registers a name in the filesystem namespace, which other processes then use to communicate with the resource manager.
