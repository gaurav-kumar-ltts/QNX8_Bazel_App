cnd_destroy()

Destroy a condition variable

Synopsis:

#include <threads.h>

void cnd_destroy( cnd_t* cond );

Arguments:

cond
A pointer to the cnd_t object that you want to destroy.

Library:

libc

Use the -l c option to qcc to link against this library. This library is usually included automatically.

Description:

The cnd_destroy() function destroys the condition variable cond. After you've destroyed a condition variable, you shouldn't reuse it until you've reinitialized it by calling cnd_init().

Any other threads that are blocked on the condition variable become unblocked.

Classification:

C11
