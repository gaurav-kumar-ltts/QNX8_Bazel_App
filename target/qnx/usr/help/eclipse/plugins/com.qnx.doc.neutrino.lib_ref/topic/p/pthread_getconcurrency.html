pthread_getconcurrency()

Get the level of thread concurrency

Synopsis:

#include <pthread.h>

int pthread_getconcurrency( void );

Library:

libc

Use the -l c option to qcc to link against this library. This library is usually included automatically.

Description:

The QNX OS doesn't support the multiplexing of user threads on top of several kernel scheduled entities. As such, the pthread_setconcurrency() and pthread_getconcurrency() functions are provided for source code compatibility but they have no effect when called. To maintain the function semantics, the new_level parameter is saved when pthread_setconcurrency() is called so that a subsequent call to pthread_getconcurrency() returns the same value.

Returns:

The concurrency level set by a previous call to pthread_setconcurrency(), or 0 if there was no previous call.

Classification:

POSIX 1003.1 OB XSI. This function is marked as obsolescent, and may be removed from a future version of the standard.

Safety:  
Cancellation point No
Signal handler Yes
Thread Yes
