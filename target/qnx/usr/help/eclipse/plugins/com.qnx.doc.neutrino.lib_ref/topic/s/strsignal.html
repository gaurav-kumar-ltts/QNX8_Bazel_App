strsignal()

Return the description of a signal

Synopsis:

#include <string.h>

char *strsignal( int signo );

Arguments:

signo
The signal number that you want the description of.

Library:

libc

Use the -l c option to qcc to link against this library. This library is usually included automatically.

Description:

The strsignal() function returns a pointer to the language-dependent string describing a POSIX signal.

Returns:

A pointer to the description of the signal.

As a QNX OS extension, this function returns a pointer to an empty string if signo isn't a valid signal number or is the number of a QNX OS signal.

Note: Don't modify the array returned by this function. This array will be overwritten by subsequent calls to strsignal().

Classification:

POSIX 1003.1

Safety:  
Cancellation point No
Signal handler Yes
Thread Yes
