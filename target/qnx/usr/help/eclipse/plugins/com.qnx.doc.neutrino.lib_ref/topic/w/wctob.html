wctob()

Convert a wide character to a single-byte code

Synopsis:

#include <wchar.h>

int wctob( wint_t c );

Arguments:

c
The wide character that you want to convert.

Library:

libc

Use the -l c option to qcc to link against this library. This library is usually included automatically.

Description:

The wctob() function returns the single-byte representation of a wide character.

This function is affected by LC_CTYPE.

Returns:

The single-byte representation, or EOF if c isn't a valid single-byte character.

Classification:

ANSI, POSIX 1003.1

Safety:  
Cancellation point No
Signal handler Yes
Thread Yes
