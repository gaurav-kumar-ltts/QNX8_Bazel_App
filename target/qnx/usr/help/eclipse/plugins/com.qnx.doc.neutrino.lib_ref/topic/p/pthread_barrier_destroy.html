pthread_barrier_destroy()

Destroy a barrier object

Synopsis:

#include <pthread.h>

int pthread_barrier_destroy(
       pthread_barrier_t * barrier );

Arguments:

barrier
A pointer to the pthread_barrier_t object that you want to destroy.

Library:

libc

Use the -l c option to qcc to link against this library. This library is usually included automatically.

Description:

The pthread_barrier_destroy() function destroys the barrier referenced by barrier and releases any resources used by the barrier. Before you reuse the barrier, you must reinitialize it by calling pthread_barrier_init().

Returns:

EBUSY
The barrier is in use.
EINVAL
Invalid barrier.
EOK
Success.

Classification:

POSIX 1003.1

Safety:  
Cancellation point No
Signal handler Yes
Thread Yes
