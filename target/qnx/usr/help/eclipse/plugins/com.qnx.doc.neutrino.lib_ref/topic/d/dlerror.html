dlerror()

Get dynamic loading diagnostic information

Synopsis:

#include <dlfcn.h>

char *dlerror( void );

Library:

libc

Use the -l c option to qcc to link against this library. This library is usually included automatically.

Description:

The dlerror() function returns a NULL-terminated string (with no trailing newline) describing the last error that occurred during a call to one of the dl*() functions. If no dynamic-linking errors have occurred since it was last invoked, dlerror() returns NULL.

Note: The dlerror() function is available only to dynamically linked processes. Don't modify the string that this function returns.

Returns:

A pointer to an error description, or NULL.

Classification:

POSIX 1003.1

Safety:  
Cancellation point No
Signal handler No
Thread Yes
