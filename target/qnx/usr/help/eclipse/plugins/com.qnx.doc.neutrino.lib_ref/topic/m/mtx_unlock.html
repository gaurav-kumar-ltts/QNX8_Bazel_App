mtx_unlock()

Unlock a mutex

Synopsis:

#include <threads.h>

int mtx_unlock( mtx_t *mutex );

Arguments:

mutex
A pointer to the mtx_t object that you want to unlock.

Library:

libc

Use the -l c option to qcc to link against this library. This library is usually included automatically.

Description:

The mtx_unlock() function unlocks the mutex mutex. The mutex should be owned by the calling thread. If there are threads blocked on the mutex then the highest priority waiting thread is unblocked and becomes the next owner of the mutex.

If the thread's priority was raised when a higher-priority thread attempted to lock the mutex, the calling thread's priority is again adjusted when it unlocks the mutex; its new priority is the maximum of its own priority and the priorities of those threads it still blocks, either directly or indirectly. For more information, see Mutexes: mutual exclusion locks in the IDE Microkernel chapter of the System Architecture guide.

If mutex has been locked more than once, it must be unlocked the same number of times before the next thread is given ownership of the mutex. This works only for recursive mutexes.

Returns:

thrd_success
Success.
thrd_error
An error occurred.

Classification:

C11

Safety:  
Cancellation point No
Signal handler No
Thread Yes
