sigmask()

Construct a mask for a signal number

Synopsis:

#include <unix.h>

#define sigmask(s) ...

Arguments:

s
The signal that you want to create a mask for. For more information, see POSIX and QNX OS signals in the documentation for SignalAction().

Library:

libc

Use the -l c option to qcc to link against this library. This library is usually included automatically.

Description:

This macro constructs the mask for a given signal number. Use sigmask() in conjunction with sigprocmask() to block or unblock specific signals.

Returns:

The signal mask.

Classification:

Unix

Safety:  
Cancellation point No
Signal handler Yes
Thread Yes

Caveats:

Use of these interfaces should be restricted to only applications written on BSD platforms. Use of these interfaces with any of the system libraries or in multithreaded applications is unsupported.
