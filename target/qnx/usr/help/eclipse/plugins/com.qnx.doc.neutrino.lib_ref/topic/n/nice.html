nice()

Returns 0

Synopsis:

#include <unistd.h>

int  nice( int incr );

Arguments:

incr
Ignored.

Library:

libc

Use the -l c option to qcc to link against this library. This library is usually included automatically.

Description:

The nice() function is provided for compatibility purposes. It does nothing, but returns 0.

Returns:

0

Classification:

POSIX 1003.1 XSI
