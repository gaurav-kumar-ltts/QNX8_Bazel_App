This chapter describes the API components whose names begin with L.

  • labs()
    Calculate the absolute value of a long integer
  • lchown()
    Change the user ID and group ID of a file or symbolic link
  • lcong48()
    Initialize a sequence of pseudo-random numbers
  • ldexp(), ldexpf(), ldexpl()
    Load exponent: multiply a floating-point number by an integral power of 2
  • ldiv(), lldiv()
    Perform division on long or long long integers
  • lfind()
    Find an entry in a linear search table
  • lgamma(), lgamma_r(), lgammaf(), lgammaf_r(), lgammal(), lgammal_r()
    Log gamma function
  • libunwind-nto
    QNX OS support in the remote unwinder (libunwind)
  • link()
    Create a link to an existing file
  • linkat()
    Create a link to an existing file located at a given path
  • lio_listio(), lio_listio64()
    Initiate a list of I/O requests
  • llabs()
    Calculate the absolute value of a long long integer
  • llrint(), llrintf(), llrintl()
    Round a floating-point number to the nearest integer value, using the current rounding direction
  • llround(), llroundf(), llroundl()
    Round a floating-point number to the nearest integer value
  • localeconv()
    Set numeric formatting according to the current locale
  • localtime()
    Convert calendar time to local time
  • localtime_r()
    Convert calendar time to local time
  • lockf(), lockf64()

  • log(), logf(), logl()
    Compute the natural logarithm of a number
  • log10(), log10f(), log10l()

  • log1p(), log1pf(), log1pl()

  • logb(), logbf(), logbl()

  • login_tty()

  • longjmp()

  • lrand48()

  • lrint(), lrintf(), lrintl()

  • lround(), lroundf(), lroundl()
    Round a floating-point number to the nearest integer value
  • lsearch()
    Perform a linear search in an array
  • lseek(), lseek64()

  • lstat(), lstat64()
