tcsetsize()

Set the size of a character device

Synopsis:

#include <termios.h>

int tcsetsize( int filedes,
               int rows,
               int cols );

Arguments:

filedes
A file descriptor that's associated with the device whose size you want to set.
rows, cols
The number of rows and columns that you want to use.

Library:

libc

Use the -l c option to qcc to link against this library. This library is usually included automatically.

Description:

The tcsetsize() function sets the size of the character device associated with filedes to the given number of rows and columns.

Returns:

0
Success.
-1
An error occurred (errno is set).

Errors:

EACCES
The filedes argument isn't associated with a controlling terminal.
EBADF
The filedes argument isn't a valid file descriptor.
EINTR
A signal interrupted the operation before it could complete.
EINVAL
The rows or cols argument is invalid.
ENOTTY
The file associated with filedes isn't a terminal.
