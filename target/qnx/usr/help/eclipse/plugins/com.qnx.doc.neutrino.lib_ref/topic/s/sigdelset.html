sigdelset()

Delete a signal from a set

Synopsis:

#include <signal.h>

int sigdelset( sigset_t *set, 
               int signo );

Arguments:

set
A pointer to the sigset_t object that you want to remove the signal from.
signo
The signal that you want to remove. For more information, see POSIX and QNX OS signals in the documentation for SignalAction().

Library:

libc

Use the -l c option to qcc to link against this library. This library is usually included automatically.

Description:

The sigdelset() function deletes signo from the set pointed to by set.

Returns:

0
Success.
-1
An error occurred (errno is set).

Errors:

EINVAL
The signal signo isn't valid.

Examples:

See sigemptyset().

Classification:

POSIX 1003.1

Safety:  
Cancellation point No
Signal handler Yes
Thread Yes
