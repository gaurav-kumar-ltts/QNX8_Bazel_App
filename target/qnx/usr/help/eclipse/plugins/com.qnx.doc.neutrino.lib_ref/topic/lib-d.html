This chapter describes the API components whose names begin with D.

  • daemon()
    Run a process in the background
  • daylight
    Indicator of support for daylight saving time in the locale
  • DebugBreak()
    Enter the process debugger
  • delay()
    Suspend a calling thread for a given length of time
  • devctl(),devctlv()
    Control a device
  • difftime()
    Calculate the difference between two times
  • dircntl()
    Control an open directory
  • dirent, dirent64
    Data structure for a directory entry
  • dirfd()
    Extract the file descriptor for a DIR stream
  • dirname()
    Find the parent directory part of a file pathname
  • dispatch_block()
    Block while waiting for an event
  • dispatch_context_alloc()
    Return a dispatch context
  • dispatch_context_free()
    Free a dispatch context
  • dispatch_create()
    Allocate a dispatch structure and create the channel associated with it
  • dispatch_create_channel()
    Allocate a dispatch structure, specifying a channel ID
  • dispatch_destroy()
    Destroy a dispatch handle, without cleaning up the dispatch framework
  • dispatch_handler()
    Handle events received by dispatch_block()
  • dispatch_timeout()
    Set a timeout
  • dispatch_unblock()
    Unblock a thread that is blocked on a dispatch handle
  • div()
    Calculate a quotient and remainder
  • dl_iterate_phdr()
    Iterate over the shared objects that are loaded into a process's address space
  • dladdr()
    Translate an address to symbolic information
  • dlclose()
    Close a shared object
  • dlerror()
    Get dynamic loading diagnostic information
  • dlopen()
    Open a shared library
  • dlsym()
    Get the address of a symbol in a shared object
  • dprintf()
    Write output to a file associated with a file descriptor
  • drand48()
    Generate a pseudo-random double
  • dup()
    Duplicate a file descriptor
  • dup2()
    Duplicate a file descriptor, specifying the new descriptor
  • dupfd()
    Duplicate a file descriptor from another process
  • dupfd_getinfo()
    Fetch the information registered by calling dupfd_register()
  • dupfd_register()
    Register a file descriptor to be duplicated by another process
  • dupfd_unregister()
    Unregister a handle that was returned by a call to dupfd_register()
