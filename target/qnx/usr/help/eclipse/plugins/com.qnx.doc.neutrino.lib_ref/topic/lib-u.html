This chapter describes the API components whose names begin with U.

  • ualarm()
    Schedule an alarm
  • umask()
    Set the file-mode creation mask for the process
  • umount()
    Unmount a filesystem
  • UNALIGNED_PUT16()
    Write a misaligned 16-bit value safely
  • UNALIGNED_PUT32()
    Write a misaligned 32-bit value safely
  • UNALIGNED_PUT64()
    Write a misaligned 64-bit value safely
  • UNALIGNED_RET16()
    Access a misaligned 16-bit value safely
  • UNALIGNED_RET32()
    Access a misaligned 32-bit value safely
  • UNALIGNED_RET64()
    Access a misaligned 64-bit value safely
  • uname()
    Get information about the operating system
  • ungetc()
    Push a character back onto an input stream
  • ungetwc()
    Push a wide character back onto an input stream
  • _unregister_ioctl_handler()
    Unregister an I/O control handler
  • unlink()
    Remove a link to a file
  • unlinkat()
    Remove a link to a file at a given location
  • unlockpt()
    Unlock a pseudo-terminal master/slave pair
  • unsetenv()
    Remove an environment variable
  • usleep()
    Suspend a thread for a given number of microseconds
  • utime()
    Set the modification time for a file or directory
  • utimensat()
    Set the access and modification times for a file
  • utimes()
    Set a file's access and modification times
  • utmp
    Entry in a user-information file
  • utmpname()
    Specify a different user information file
