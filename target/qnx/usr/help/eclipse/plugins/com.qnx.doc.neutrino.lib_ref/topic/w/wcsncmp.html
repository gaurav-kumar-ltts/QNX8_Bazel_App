wcsncmp()

Compare two wide-character strings, up to a given length

Synopsis:

#include <wchar.h>

int wcsncmp( const wchar_t * ws1,
             const wchar_t * ws2,
             size_t n );

Arguments:

ws1, ws2
The wide-character strings that you want to compare.
n
The maximum number of wide characters that you want to compare.

Library:

libc

Use the -l c option to qcc to link against this library. This library is usually included automatically.

Description:

The wcsncmp() function compares up n wide characters from the strings pointed to by ws1 and ws2.

Returns:

< 0
ws1 is less than ws2.
0
ws1 is equal to ws2.
> 0
ws1 is greater than ws2.

Classification:

ANSI, POSIX 1003.1

Safety:  
Cancellation point No
Signal handler Yes
Thread Yes
