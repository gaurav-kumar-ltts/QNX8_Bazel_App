This chapter describes the API components whose names begin with J.

  • j0(), j0f()
    Compute a Bessel function of the first kind of order 0
  • j1(), j1f()
    Compute a Bessel function of the first kind of order 1
  • jn(), jnf()
    Compute a Bessel function of the first kind of a given order
  • jrand48()
    Generate a pseudo-random signed long integer in a thread-safe manner
