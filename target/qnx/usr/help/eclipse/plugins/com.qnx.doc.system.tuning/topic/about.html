About This Guide

This guide provides a discussion of performance-related considerations and specific suggestions for improving the performance of the QNX OS for your specific environment.

The default settings of your QNX OS provide a great baseline level of performance for general-purpose operations. However, if you want to optimize your system for a specific environment, then this guide provides some potential tuning options.
To find out about: Go to:
Optimizing your filesystems; for example, speeding up sequential reading and writing, subsequent scans and opens, and repeated lookups Filesystems
Tuning networking performance; for example, reducing the startup time for the networking stack or making configuration changes that improve network throughput Networking stack (io-sock)
Note: Any setting adjustments to improve one area of performance may negatively impact other measures of performance. Always test the system environment when determining the optimal setting for each option.
