init_mmu()

Set up the processor for virtual addressing mode by setting up page-mapping hardware and enabling the pager.

Synopsis:

#include "board_startup.h"
				
void init_mmu (void)

Arguments:

None.

Description:

This function is only relevant on systems with an MMU. It performs different tasks on ARM and x86 platforms:

ARM
Sets up the page tables.
x86
Sets up the page tables. This set up includes special mappings to physical address ranges, such as mappings to ensure that the memory between 640 KB and 1 MB won't be used for DRAM, to prevent conflicts with any possible legacy code.
