About This Guide

The Building Embedded Systems guide is intended for developers who are developing or building BSPs for QNX OS embedded systems.

This guide provides information about how to build and/or customize:
  • QNX Board Support Packages (BSPs)
  • QNX OS embedded systems
  • the startup of QNX OS embedded systems

It is organized thematically rather than sequentially; that is, you should refer to the chapters relevant to the task you are doing, rather than work through the book from start to finish. For instance, if you need to learn how to customize the QNX Initial Program Loader (IPL), you should first read the Overview chapter, then the Initial Program Loaders (IPLs) chapter. Because you will likely be working with a QNX BSP, the BSP chapters are near the front of the guide.

Note: We assume that you've already installed the QNX OS and that you're familiar with its architecture. For an overview, see the QNX OS System Architecture guide.
