Booting QNX OS

To boot your board, follow the platform-specific instructions in the BSP User's Guide for that board.

Booting QNX OS on your target board usually involves the following steps:
  1. Set hardware switches on the board, if required.
  2. Connect the board's power supply.
  3. Power up the board.
When the board has booted, you can use any built-in shell command or command residing in the OS image to test if the QNX OS is running. For example, from the command line on your target system, you can type:
