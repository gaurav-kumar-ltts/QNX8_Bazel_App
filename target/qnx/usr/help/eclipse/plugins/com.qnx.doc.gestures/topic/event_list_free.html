event_list_free()

Free an event list

Synopsis:

#include <gestures/event_list.h>
void event_list_free(struct event_list *list)

Arguments:

list
A pointer to the event list.

Library:

libgestures

Description:

This function resets the members of the specified list and frees the associated memory.

Returns:

Nothing.
