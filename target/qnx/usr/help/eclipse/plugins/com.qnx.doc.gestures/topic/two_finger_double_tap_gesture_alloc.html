two_finger_double_tap_gesture_alloc()

Allocate and initialize the two-finger double tap gesture structure

Synopsis:

#include <gestures/two_finger_double_tap.h>
gesture_two_finger_double_tap_t* two_finger_double_tap_gesture_alloc(two_finger_double_tap_params_t *params,
                                                                     gesture_callback_f callback,
                                                                     struct gestures_set *set)

Arguments:

params
The two-finger double tap gesture parameters.
callback
The function to invoke when the two-finger double tap gesture changes state.
set
The gesture set to add this two-finger double tap gesture to.

Library:

libgestures

Description:

This function allocates a new two-finger double tap gesture data structure, initializes it with the specified parameters and callback function, and adds it to the specified gesture set.

Returns:

An initialized two-finger double tap gesture.
