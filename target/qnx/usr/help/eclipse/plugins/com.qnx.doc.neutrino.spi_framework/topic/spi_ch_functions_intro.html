SPI driver functions

This chapter defines spi_init() and the SPI driver functions in the spi_funcs_t structure.

Each SPI driver must implement the spi_init() function to access the device driver where io-spi gets the SPI driver functions in spi_funcs_t.

  • spi_init()
    Initialize the SPI hardware interface
  • spi_fini()
    Clean up the low-level driver and free any associated memory
  • drvinfo()
    Get the SPI driver information
  • devinfo()
    Obtain the SPI device information
  • setcfg()
    Set the SPI device configuration
  • xfer()
    Initiate a SPI transaction
  • dma_xfer()
    Initiate a DMA transaction
  • dma_allocbuf()
    Allocate a DMA buffer
  • dma_freebuf()
    Free a DMA buffer
