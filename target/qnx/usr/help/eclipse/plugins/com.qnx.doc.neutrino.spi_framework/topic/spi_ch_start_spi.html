Starting a SPI device driver

Run a board-specific SPI device driver

Syntax:

The following code block shows the SPI driver generic command line options, where XXX is a specific name to the target board: 
spi-XXX [-c config_file] [-v]

Options:

-c config_file
The path to the SPI configuration file. The default path is /etc/system/config/spi/spi.conf.
-v
Increase verbosity. This overrides the verbose value in the config file.

Description:

The SPI driver runs with either:
  • the default config file, /etc/system/config/spi/spi.conf: 
    spi-XXX
    or:
  • a custom config file: 
    spi-XXX -c config_file

Example:

Let's say we want to start the SPI driver for a Raspberry Pi with a custom config file, then we use: 
spi-bcm2711 -c /etc/config/spi-bcm2711.cfg
