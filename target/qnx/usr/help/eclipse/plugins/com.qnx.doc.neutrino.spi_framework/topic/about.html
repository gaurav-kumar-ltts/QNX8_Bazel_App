About this Technote

The SPI (Serial Peripheral Interface) Framework Technote describes how to use the APIs of the SPI framework.

This technote covers the following topics:
  • understanding the SPI framework
  • interfacing between the SPI applications and io-spi
  • interfacing between io-spi and the SPI drivers
  • starting a SPI device driver
  • configuring the SPI
