qcrypto_key_args_t

Public or private key arguments

Synopsis:

#include <qcrypto/qcrypto_keys.h>

typedef struct {
    union {
        struct {
            size_t bits;
            size_t pubexp;
        } rsa;
        struct {
            size_t psize;
        } dsa;
        struct {
            qcrypto_ec_curve_t curve;
            qcrypto_ec_key_type_t type;
        } ec;
        struct {
            size_t psize;
        } dh;
        void* private;
    };
} qcrypto_key_args_t;

Data:

size_t bits

The modulus size in bits.

size_t pubexp

The public exponent value.

size_t psize

The prime size in bits.

qcrypto_ec_curve_t curve

The ECC curve.

qcrypto_ec_key_type_t type

The ECC key type.

void* private

Private arguments to pass for other key types.

Library:

devcr
