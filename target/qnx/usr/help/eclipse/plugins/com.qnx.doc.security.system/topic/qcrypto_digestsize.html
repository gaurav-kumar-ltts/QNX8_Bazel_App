qcrypto_digestsize()

Query the digest size

Synopsis:

#include <qcrypto/qcrypto.h>
size_t qcrypto_digestsize(qcrypto_ctx_t *ctx)

Arguments:

ctx
The algorithm context object.

Library:

libqcrypto

Description:

The maximum digest size is QCRYPTO_DIGEST_MAX_SIZE.

Returns:

The digest size in bytes.
