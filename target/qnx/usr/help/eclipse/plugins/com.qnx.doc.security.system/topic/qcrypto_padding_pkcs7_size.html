qcrypto_padding_pkcs7_size()

Calculate PKCS7 padding length

Synopsis:

#include <qcrypto/qcrypto.h>
size_t qcrypto_padding_pkcs7_size(size_t size,
                                  size_t blocksize)

Arguments:

size
The input data size.
blocksize
The algorithm blocksize to adjust the padding to.

Library:

libqcrypto

Returns:

The padding size in bytes.
