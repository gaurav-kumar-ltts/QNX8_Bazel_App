TomCrypt plugin

The qcrypto library TomCrypt plugin provides support for the LibTomCrypt cryptographic toolkit.

Required libraries

  • libqcrypto.so.1
  • qcrypto-tomcrypt.so

Supported Algorithms

Type Supported
Ciphers aes-128-ecb, aes-192-ecb, aes-256-ecb
Key generators symmetric
Digests sha224, sha256, sha384, sha512, sha512-224, sha512-256
RNGs urandom
