Key encoding formats

Definitions:

#define QCRYPTO_KEY_FMT_UNKNOWN 0u

Unknown key format. 

#define QCRYPTO_KEY_FMT_SYMMETRIC 1u

Symmetric key format. 

#define QCRYPTO_KEY_FMT_DER 2u

Public or private key DER format. 

#define QCRYPTO_KEY_FMT_PEM 3u

Public or private key PEM format. 

#define QCRYPTO_KEY_FMT_MAX 4u

Maximum value supported internally by the qcrypto library. 

#define QCRYPTO_KEY_FMT_PRIVATE 100u

Value above which custom formats can use.
