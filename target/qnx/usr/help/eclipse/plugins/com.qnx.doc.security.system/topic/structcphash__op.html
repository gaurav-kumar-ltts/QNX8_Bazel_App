cphash_op_t

CIOCCPHASH command

Synopsis:

#include <dev/crypto/cryptodev.h>

typedef struct cphash_op {
    uint64_t dst_ses;
    uint64_t src_ses;
} cphash_op_t;

Data:

uint64_t dst_ses

The destination session.

uint64_t src_ses

The source session.

Library:

devcr

Description:

This command copies a digest state from one session to another to continue the digest operation.
