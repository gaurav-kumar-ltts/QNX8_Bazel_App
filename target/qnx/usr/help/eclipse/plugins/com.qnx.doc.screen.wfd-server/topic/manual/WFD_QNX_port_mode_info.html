WFD_QNX_port_mode_info

WFD_QNX_port_mode_info

Description

This extension provides port mode information using the attributes below.

Attributes

WFD_PORT_MODE_ASPECT_RATIO_QNX 0x7606

Specify the aspect ration the display will have when mode is set.

Storage type: @c WFDfloat read-only

Accessors:
  • wfdGetPortModeAttribf()
WFD_PORT_MODE_PREFERRED_QNX 0x7607

Specify the preferred mode. A WFD client should set a preferred mode if the user has not selected one.

Storage type: @c WFDboolean read-only

Range: true or false

Accessors:
  • wfdGetPortModeAttribi()
Parent topic: wfdext.h
