Utilities and binaries

WFD server includes some utilities and binaries to help with calibration, debugging, and demonstrating features.

Before you can run these utilities and binaries, you need to ensure that the shared objects that they depend on are included in your system image. See the Shared libraries section of the Building Embedded Systems guide for more information on how to determine which shared objects you need.

WFD sever utilities are the following:

wfd-demo
Initialize the display with a QNX logo
wfd-power-mode
Set the power mode on a port
wfd-screenshot
Write the contents of a port to memory and a bmp file
wfd-server-info
Provide WFD system information
wfd-writeback
Write the contents of a port to memory
