wfdReadPixelsFromSourceQNX()

Read color values for the image from a specified source

Synopsis:

#include <wfd/wfdext.h>
WFDErrorCode wfdReadPixelsFromSourceQNX(WFDDevice device, WFDSource source, WFDint x, WFDint y, WFDint width, WFDint height, WFDint format, void *data)

Arguments:

device
A WFD device handle
source
A WFD source handle
x
Starting x position
y
Starting y position
width
Width of the image to read
height
Height of the image to read
format
The format that corresponds to the color values written. Reference the wfd-server header file for more information. Depending on your implementation, some formats might be supported as read back.
data
Destination buffer for the read color values

Library:

libWFDclient

Returns:

WFD_ERROR_NONE on success, or an OpenWFD error code on failure. This function does not affect values returned by wfdGetError().
