wfdDestroyWFDEGLImagesQNX()

Deallocate memory that came from wfdCreateWFDEGLImagesQNX()

Synopsis:

#include <wfd/wfdext.h>
WFDErrorCode wfdDestroyWFDEGLImagesQNX(WFDDevice device, WFDint count, WFDEGLImage *images)

Arguments:

device
The WFD device handle from which the images were allocated.
count
The number of buffers to deallocate.
images
A pointer to an array containing the WFDEGLImage objects to free. Each object must be a pointer that came from wfdCreateWFDEGLImagesQNX(), not a pointer to an equivalent object. Objects that were allocated together do not have to be freed together.

Library:

libWFDclient

Returns:

WFD_ERROR_NONE on success, or an OpenWFD error code on failure. This function does not affect values returned by wfdGetError().
