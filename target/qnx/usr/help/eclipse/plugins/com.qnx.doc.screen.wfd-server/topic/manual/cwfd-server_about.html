About OpenWF Display Server

The OpenWF Display Server (wfd-server) is a resource manager that provides applications the ability to show image buffers directly to the display controller via the OpenWF Display API.

Note: To distinguish between different types of applications, we'll use the following terminology in this document:
  • Screen application: an application that uses Screen and the Screen API to show content to a display
  • OpenWFD-based application: an application that shows image buffers directly to the display controller without using Screen or the Screen API

This guide describes how to configure and use wfd-server. For more information on resource managers, go to the Resource Managers chapter of the QNX OSSystem Architecture guide.
