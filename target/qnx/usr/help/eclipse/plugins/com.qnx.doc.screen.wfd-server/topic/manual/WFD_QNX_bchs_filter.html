WFD_QNX_bchs_filter

WFD_QNX_bchs_filter

Description

This extension provides attributes for controlling the brightness, contrast, hue, and saturation applied to a pipeline's image.

The values are applied before layer blending. Normally, they're applied during YCbCr-to-RGB conversion, and therefore don't affect buffers already in an RGB format.

Attributes

WFD_PIPELINE_BRIGHTNESS_QNX 0x7750

Specify desired brightness

Storage type: WFDint read/write

range: [-255, 255] from darkest to brightest

Default: 0

Accessors:
  • wfdGetPipelineAttribi()
  • wfdSetPipelineAttribi()
WFD_PIPELINE_CONTRAST_QNX 0x7751

Specify desired contrast

Storage type: WFDint read/write

range: [-128, 127] from least to most contrast

Default: 0

Accessors:
  • wfdGetPipelineAttribi()
  • wfdSetPipelineAttribi()
WFD_PIPELINE_HUE_QNX 0x7752

Specify desired hue

Storage type: WFDint read/write

range: [-128, 127]

Default: 0

Accessors:
  • wfdGetPipelineAttribi()
  • wfdSetPipelineAttribi()
WFD_PIPELINE_SATURATION_QNX 0x7753

Specify desired saturation level

Storage type: WFDint read/write

range: [-128, 127] from least to most saturation

Default: 0

Accessors:
  • wfdGetPipelineAttribi()
  • wfdSetPipelineAttribi()
