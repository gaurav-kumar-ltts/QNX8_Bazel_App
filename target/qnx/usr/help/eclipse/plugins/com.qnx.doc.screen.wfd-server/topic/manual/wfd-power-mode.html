wfd-power-mode

Set the power mode on a port

Syntax:

wfd-power-mode  [-ddevice_id]
                [-pport_id]
                [-opower_mode]

Runs on:

QNX OS

Options:

-d device_id
Specify the device ID. Default is 2.
-p port_id
Specify the port ID. Default is 2.
-opower_mode
Specify the power mode. Choose from the following:
  • 0 for WFD_POWER_MODE_OFF (default)
  • 1 for WFD_POWER_MODE_SUSPEND
  • 2 for WFD_POWER_MODE_LIMITED_USE
  • 2 for WFD_POWER_MODE_MODE_ON

Description

Set the power mode on a port. You need to ensure that power control is enabled for the specified device or board in the graphics.conf file.
