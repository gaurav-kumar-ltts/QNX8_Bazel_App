WFD_QNX_tls_error_mode

Description

This extension allows per-thread error values to be accessed.

Attributes

WFD_DEVICE_GETERROR_USE_TLS_QNX 0x42557560

Storage type: WFDint read/write

Range: 0 to disable, any non-zero value to enable

Default: 0

Accessors:
  • wfdGetDeviceAttribi()
  • wfdSetDeviceAttribi()
Parent topic: wfdext.h
