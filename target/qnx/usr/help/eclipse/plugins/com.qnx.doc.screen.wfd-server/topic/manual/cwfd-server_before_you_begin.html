Before you begin

Install the QNX Software Center

To get started, you must have the QNX Software Center version 2.0 or later installed. If you've already installed it, choose Help > About to check the version. If you have an earlier version, the QNX Software Center should prompt you to update it; if it doesn't, uninstall the QNX Software Center, go to the QNX website and get the latest version of the QNX Software Center.

To install the latest version of the QNX Software Center, do the following steps:

  1. Go to our website, www.qnx.com.
  2. Log in to your myQNX account.
  3. Go to the Download area, and download the QNX Software Center archive. Follow the instructions provided in the installation note for the QNX Software Center.

The QNX Software Center uses the list of registered products displayed in your myQNX account to determine which software packages you're eligible to install. For more information, see the myQNX License Manager and QNX Software Center User's Guide that's posted with the archive.

Install QNX SDP 8.0 and a compatible version of Screen

From QNX Software Center, install QNX SDP 8.0 and a version of Screen that's compatible with the OpenWF Display Server. For more information on how to add a new installation, see the myQNX License Manager and QNX Software Center User's Guide.

Install the OpenWF Display Server

From QNX Software Center, the OpenWF Display Server must be installed on top of an existing QNX SDP 8.0 installation with a compatible version of QNX SDP 8.0 Screen.

Install QNX SDP 8.0 Board Support Packages

From QNX Software Center, install a processor-specific BSP that's compatible with your target. For more information on BSPs, refer to Building Embedded Systems, or to the BSP User's Guide. The BSP User's Guide that is specific to your target is also available from QNX Software Center.

Your target hardware must be compatible with QNX OS 8.0 and is supported by OpenWF Display Server. You must have the appropriate binaries that correspond to your target. In this release, OpenWF Display Server supports the following targets:

  • NXP i.MX 8QuadMax
  • TI J721E
