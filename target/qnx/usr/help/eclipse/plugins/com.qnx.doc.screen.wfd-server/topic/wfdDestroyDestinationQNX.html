wfdDestroyDestinationQNX()

Destroy a WFDDestinationQNX object

Synopsis:

#include <wfd/wfdext.h>
void wfdDestroyDestinationQNX(WFDDevice device, WFDDestinationQNX destination)

Arguments:

device
A WFD device handle.
destination
A destination handle associated with device.

Library:

libWFDclient

Description:

If an invalid handle is specified, an error will be made accessible via wfdGetError(). Otherwise, any outstanding uses of the destination will be cancelled and the destination will be deleted as soon as possible.
