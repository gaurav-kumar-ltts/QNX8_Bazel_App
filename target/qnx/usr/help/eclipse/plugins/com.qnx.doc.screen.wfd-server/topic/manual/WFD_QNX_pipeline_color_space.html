WFD_QNX_pipeline_color_space

WFD_QNX_pipeline_color_space

Description

This extension allows the setting of a pipeline's color space.

Attributes

WFD_PIPELINE_COLOR_SPACE_QNX 0x77A0

Specify the color space

Storage type: WFDint read/write

Range: Values defined below

Default: WFD_COLOR_SPACE_UNCORRECTED_QNX

Accessors:
  • wfdGetPipelineAttribi()
  • wfdSetPipelineAttribi()
Possible values include:
  • WFD_COLOR_SPACE_UNCORRECTED_QNX0x0
  • WFD_COLOR_SPACE_SRGB_QNX0x1
  • WFD_COLOR_SPACE_LRGB_QNX0x2
  • WFD_COLOR_SPACE_BT601_QNX0x3
  • WFD_COLOR_SPACE_BT601_FULL_QNX0x4
  • WFD_COLOR_SPACE_BT709_QNX0x5
  • WFD_COLOR_SPACE_BT709_FULL_QNX0x6
