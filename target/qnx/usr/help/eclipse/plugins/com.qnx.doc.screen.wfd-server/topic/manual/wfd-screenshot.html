wfd-screenshot

Write the contents of a port to memory and a bmp file

Syntax:

wfd-screenshot  [-ddevice_id]
                [-pport_id]
                [-frgba8888|rgbx8888|rgb888|rgb565|yvyu|uyvy|yuy2]

Runs on:

QNX OS

Options:

-d device_id
Specify the device ID. Default is 2.
-p port_id
Specify the port ID. Default is 2.
-frgba8888|rgbx8888|rgb888|rgb565|yvyu|uyvy|yuy2
Specify the format to capture writeback port data. The default is RGBX8888.

Description:

Take a screenshot of a port and write it to memory and a bmp files. Ensure that writeback is supported by the WFD-driver and the writeback port enabled in the Screen configuration file.
