WFD_QNX_destination_create_from_images

Description

This extension defines the preferred way to create WFDDestinationQNX objects. It depends on the following extensions:
  • WFD_QNX_destination
  • wfdCreateDestinationFromImagesQNX()
    Allocate a destination from a set of image buffers
