Five Steps to Developing a QNX OS Program

This guide will help you install the QNX Software Development Platform and QNX Toolkit IDE to quickly develop a program for a QNX OS target.

It provides a walkthrough of this process in the following topics:



1. Installation
2. Creating the QNX OS target system
3. Creating a program project
4. Compiling and linking
5. Running and debugging the program
