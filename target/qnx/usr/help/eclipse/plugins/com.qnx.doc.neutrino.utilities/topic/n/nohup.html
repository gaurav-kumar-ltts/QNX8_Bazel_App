nohup

Run a command that survives the end of its terminal (POSIX, toybox)

Syntax:

nohup command

Runs on:

QNX OS

Options:

command
The command to run.

Description:

The nohup utility redirects tty on stdin to /dev/null and tty on stdout to nohup.out.

Contributing author:

Rob Landley and the toybox project (see https://landley.net/toybox/).

This utility is provided as part of the toybox package. For information on how to enable it, see toybox.
