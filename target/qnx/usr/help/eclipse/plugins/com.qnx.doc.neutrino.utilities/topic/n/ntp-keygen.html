ntp-keygen

Generate public and private keys

Syntax:

ntp-keygen [ -deGHIMPT ] [-b modulus]
           [-c [ RSA-MD2 | RSA-MD5 | RSA-SHA | RSA-SHA1 | RSA-MDC2 |
            RSA-RIPEMD160 | DSA-SHA | DSA-SHA1 ]]
           [-C cipher] [-i group] [-l days] [-m modulus]
           [-p passwd1] [-q passwd2] [-S [ RSA | DSA ]][-s host]
           [-V nkeys]

Runs on:

QNX OS

Description:

The ntp-keygen utility that QNX OS provides is from the Network Time Protocol (NTP) Project implementation of NTP.

For a detailed description, see the documentation the NTP Project provides (https://doc.ntp.org/documentation/4.2.8-series/keygen/).
