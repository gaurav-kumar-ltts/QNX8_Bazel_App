wpa_passphrase-version

Set WPA passphrase for a SSID

Syntax:

wpa_passphrase-version [ssid] [passphrase]

Runs on:

QNX OS

Options:

ssid
The SSID whose passphrase should be derived.
passphrase
Use this passphrase. If not included on the command line, it will be read from standard input.

Description:

The wpa_passphrase utility precomputes pre-shared key (PSK) entries for network configuration blocks of a wpa_supplicant.conf file.

The number in the wpa_passphrase utility name indicates the wpa_supplicant version it supports. For example, wpa_passphrase-2.5 supports version 2.5.
