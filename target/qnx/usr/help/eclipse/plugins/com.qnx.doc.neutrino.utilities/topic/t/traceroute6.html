traceroute6

Print the route IPv6 packets take to the destination

Syntax:

traceroute6 [-adIlnNrSTUv] [-f firsthop] [-g gateway] [-m hoplimit]
            [-p port] [-q probes] [-s src] [-t tclass] [-w waittime]
            [-A as_server] target [datalen]

Runs on:

QNX OS

Description:

The traceroute6 utility that QNX OS provides is ported from FreeBSD.

For a detailed description, see the FreeBSD documentation (https://www.freebsd.org/cgi/man.cgi?query=traceroute6&sektion=8&manpath=FreeBSD+13.4-RELEASE+and+Ports).
