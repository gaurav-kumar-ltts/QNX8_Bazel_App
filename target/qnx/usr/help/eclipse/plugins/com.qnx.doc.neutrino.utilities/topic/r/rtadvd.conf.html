/etc/rtadvd.conf

Configuration file for router advertisement daemon

Name:

/etc/rtadvd.conf

Description:

This file is used with the rtadvd utility ported from FreeBSD and describes how the router advertisement packet must be constructed for each of the interfaces. You set it only when you need some special configuration.

For a detailed description, see the FreeBSD documentation (https://www.freebsd.org/cgi/man.cgi?query=rtadvd.conf&sektion=5&manpath=FreeBSD+13.4-RELEASE+and+Ports).
