setkey

Manually manipulate the IPsec SA/SP database

Syntax:

setkey [-v] -c
setkey [-v] -f filename
setkey [-Pgltv] -D
setkey [-Pv] -F
setkey [-h] -x

Runs on:

QNX OS

Description:

The setkey utility that QNX OS provides is ported from FreeBSD.

QNX OS does not support the -e option, which allows you to specify the series of operations to perform from the command line argument that follows it (-e script).

For a detailed description, see the FreeBSD documentation (https://www.freebsd.org/cgi/man.cgi?query=setkey&sektion=8&manpath=FreeBSD+13.4-RELEASE+and+Ports).
