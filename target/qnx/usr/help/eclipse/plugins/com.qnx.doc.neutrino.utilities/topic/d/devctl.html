devctl

Device control utility for io-sock

Syntax:

devctl attach device
devctl clear driver [-f] device
devctl detach [-f] device
devctl disable [-f] device
devctl enable device
devctl suspend device
devctl resume device
devctl set driver [-f] device driver
devctl rescan device
devctl delete [-f] device
devctl freeze
devctl thaw

Runs on:

QNX OS

Description:

The devctl utility that QNX OS provides is ported from FreeBSD. It adjusts the state of individual devices in the io-sock networking stack's internal device hierarchy.

For options and a detailed description, see the FreeBSD documentation (https://www.freebsd.org/cgi/man.cgi?query=devctl&sektion=8&manpath=FreeBSD+13.4-RELEASE+and+Ports).

The io-sock networking stack does not support the standard FreeBSD reset device command. For PCI devices, use pci-tool instead.
