ntpdate

Set the local time and date by polling NTP servers

Syntax:

ntpdate [-46bBdqsuv] [-a key] [-e authdelay] 
        [-k keyfile] [-o version]  [-p samples] 
        [-t timeout] server [...]

Runs on:

QNX OS

Description:

The ntpdate utility that QNX OS provides is from the Network Time Protocol (NTP) Project implementation of NTP.

For a detailed description, see the documentation the NTP Project provides (https://doc.ntp.org/documentation/4.2.8-series/ntpdate/).
