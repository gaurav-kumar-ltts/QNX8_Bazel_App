mods-usb.so

Module for USB bus devices

Syntax:

io-sock -m usb [-d driver [driver_options]]...

Runs on:

QNX OS

Options:

prefix=prefix
Only used in conjunction with mount. Matches the prefix option used when launching io-sock to specify which instance of io-sock should mount this module.

Description:

The mods-usb.so driver provides the FreeBSD USB bus API for USB bus devices. Any driver that requires USB requires this module. For more information, see Starting io-sock and Driver Management in the High-Performance Networking Stack User's Guide.
