/etc/ssh/moduli

System moduli file for sshd

Name:

/etc/ssh/moduli

Description:

The /etc/ssh/moduli file contains the system-wide Diffie-Hellman prime moduli for sshd. For more information, see the OpenSSH documentation: https://man.openbsd.org/moduli
