/etc/pf.conf

Packet filter configuration file

Name:

/etc/pf.conf

Description:

The pf packet filter modifies, drops, or passes packets according to rules or definitions specified in pf.conf. The default location of this file is /etc/pf.conf.

For more information, see Packet Filtering in the High-Performance Networking Stack User's Guide, and the FreeBSD documentation (https://www.freebsd.org/cgi/man.cgi?query=pf.conf&sektion=5&manpath=FreeBSD+13.4-RELEASE+and+Ports).
