etherswitchcfg

Configure a built-in Ethernet switch

Syntax:

etherswitchcfg [-f control_file] info
etherswitchcfg [-f control_file] config command parameter
etherswitchcfg [-f control_file] phy phy.register[=value]
etherswitchcfg [-f control_file] portnumber [flags] command parameter
etherswitchcfg [-f control_file] reg register[=value]
etherswitchcfg [-f control_file] vlangroupnumber command parameter

Runs on:

QNX OS

Description:

The etherswitchcfg utility that QNX OS provides is ported from FreeBSD.

For a detailed description, see the FreeBSD documentation (https://man.freebsd.org/cgi/man.cgi?query=etherswitchcfg&sektion=8&manpath=FreeBSD+13.4-RELEASE+and+Ports).
