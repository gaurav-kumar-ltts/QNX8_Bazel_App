logout

Terminate a session (UNIX)

Syntax:

logout

Runs on:

QNX OS

Options:

None.

Description:

The logout command terminates all the processes in the same process group as logout terminates itself (being the only process in its group).

You can execute this command only from a shell invoked by a login command; otherwise a message is printed and the logout command is ignored.
