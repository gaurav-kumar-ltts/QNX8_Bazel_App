unix2dos

Convert newline format from Unix to DOS (POSIX, toybox)

Syntax:

unix2dos [file...]

Runs on:

QNX OS

Options:

file
The pathname of a file to use as input.

If no files are listed, copy from stdin. A filename with the dash character (-) is a synonym for standard input.

Description:

The unix2dos utility converts the newline format from Unix (\n) to DOS (\r\n).

This utility is provided as part of the toybox package. For information on how to enable it, see toybox.

Contributing author:

Rob Landley and the toybox project (see https://landley.net/toybox/).
