rtadvd

Router advertisement daemon

Syntax:

rtadvd [-dDfRs] [-c configfile] [-C ctlsock] [-M ifname] [-p pidfile]
       [interface ...]

Runs on:

QNX OS

Description:

The rtadvd utility that QNX OS provides is ported from FreeBSD.

For a detailed description, see the FreeBSD documentation (https://www.freebsd.org/cgi/man.cgi?query=rtadvd&sektion=8&manpath=FreeBSD+13.4-RELEASE+and+Ports).
