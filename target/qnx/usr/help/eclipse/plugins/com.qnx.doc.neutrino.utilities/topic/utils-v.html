This chapter describes the utilities, etc. whose names start with V.

  • valgrind
    Run and analyze a program with a Valgrind tool, using the specified Valgrind and program options
  • vi
    Visual interface editor clone (UNIX)
  • view
    Visual interface editor clone (UNIX)
  • vmstat
    Display io-sock virtual memory statistics
  • vpctl
    Configure a networking interface that connects a hypervisor host and a virtio-net vdev
