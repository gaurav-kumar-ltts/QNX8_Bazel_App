This chapter describes the utilities, etc. whose names start with K.

  • kdserver
    QVM guest dump/kernel dump server
  • kdumper
    Write a kernel dump
  • kill
    Terminate or signal processes (POSIX)
  • ksh
    Public domain Korn shell command interpreter (UNIX)
