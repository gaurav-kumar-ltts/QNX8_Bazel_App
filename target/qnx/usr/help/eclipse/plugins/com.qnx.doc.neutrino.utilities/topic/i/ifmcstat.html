ifmcstat

Dump multicast group management statistics per interface

Syntax:

ifmcstat [-i interface] [-f address-family] [-v] [-K] [-M core]
         [-N system]

Runs on:

QNX OS

Description:

The ifmcstat utility that QNX OS provides is ported from FreeBSD.

For a detailed description, see the FreeBSD documentation (https://www.freebsd.org/cgi/man.cgi?query=ifmcstat&sektion=8&manpath=FreeBSD+13.4-RELEASE+and+Ports).
