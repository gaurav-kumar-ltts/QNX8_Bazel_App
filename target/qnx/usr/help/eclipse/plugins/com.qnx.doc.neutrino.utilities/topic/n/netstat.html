netstat

Show network status

Syntax:

netstat [--libxo] [-46AaCLnPRSTWx] [-f protocol_family | -p protocol]

netstat -i | -I interface
        [--libxo] [-46abdhnW] [-f address_family]

netstat -w wait
        [--libxo] [-I interface] [-46d] [-q howmany]

netstat -s
        [--libxo] [-46sz] [-f protocol_family | -p protocol]

netstat -i | -I interface -s
        [--libxo] [-46s] [-f protocol_family | -p protocol]

netstat -m
        [--libxo]

netstat -B
        [--libxo] [-z] [-I interface]

netstat -r
        [--libxo] [-46nW] [-F fibnum] [-f address_family]

netstat -rs
        [--libxo] [-s]

netstat -g
        [--libxo] [-46W] [-f address_family]

netstat -gs
        [--libxo] [-46s] [-f address_family]

netstat -Q
        [--libxo]

Runs on:

QNX OS

Description:

The netstat utility that QNX OS provides is ported from FreeBSD.

QNX OS does not support the options -j, -M, or -N for netstat.

For a detailed description, see the FreeBSD documentation (https://www.freebsd.org/cgi/man.cgi?query=netstat&sektion=1&manpath=FreeBSD+13.4-RELEASE+and+Ports).
