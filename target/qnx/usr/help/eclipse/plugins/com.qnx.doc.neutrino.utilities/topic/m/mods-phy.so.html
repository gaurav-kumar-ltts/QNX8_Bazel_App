mods-phy.so

Module for Ethernet PHY devices

Syntax:

io-sock -m phy [-d driver [driver_options]]...

Runs on:

QNX OS

Options:

prefix=prefix
Only used in conjunction with mount. Matches the prefix option used when launching io-sock to specify which instance of io-sock should mount this module.

Description:

The mods-phy.so module provides common Ethernet PHY drivers that work with the miibus layer in io-sock (more information at https://man.freebsd.org/cgi/man.cgi?query=miibus&sektion=4&manpath=FreeBSD+13.4-RELEASE+and+Ports).

For more information, see Starting io-sock and Driver Management in the High-Performance Networking Stack User's Guide.
