ssh-keysign

SSH helper program for host-based authentication

Syntax:

ssh-keysign

Runs on:

QNX OS

Options:

None.

Description:

The ssh-keysign program is used by ssh to access the local host keys and generate the digital signature required during host-based authentication with SSH protocol version 2. For more information, see the OpenSSH documentation: https://man.openbsd.org/ssh-keysign

This program uses the OpenSSL library for cryptography services.
