dumpefs

Dump an embedded filesystem

Syntax:

dumpefs [-tuv]  embedded files

Runs on:

QNX OS, Linux, Microsoft Windows

Options:

-t
Dump the text of each extent.
-u
Output a unit summary, including the size of the filesystem, and the amount and percentage of space used.
-v
Be verbose.

Description:

The dumpefs utility dumps the contents of an embedded filesystem.

License checking

The dumpefs utility checks for a valid QNX license key before performing any operation. If the license check fails, the utility stops running and displays a diagnostic message. A license check may fail if the license key is expired, missing, or not currently activated, or if the key doesn’t contain the permissions needed to run the utility.
