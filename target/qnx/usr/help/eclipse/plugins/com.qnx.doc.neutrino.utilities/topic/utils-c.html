This chapter describes the utilities, etc. whose names start with C.

  • c++filt
    Demangle C++ and Java symbols
  • cal
    Print a calendar (POSIX, toybox)
  • cam-cdrom.so
    Provide a common access method for CD-ROMs
  • cam-disk.so
    Provide a common access method for hard disks
  • cam-optical.so
    Provide a common access method for optical disks
  • canctl
    Control a CAN (Controller Area Network) device
  • cat
    Concatenate and print files (POSIX, toybox)
  • chattr
    Manipulate the attributes of a file (QNX OS)
  • chemod
    Change file extended mode bits (non-POSIX)
  • chgrp
    Change file group ownership (POSIX, toybox)
  • chkdosfs
    Check a DOS (FAT-12/16/32) filesystem for consistency (QNX OS)
  • chkqnx6fs
    Check an entire Power-Safe filesystem for consistency (QNX OS)
  • chmod
    Change file modes (POSIX, toybox)
  • chown
    Change the ownership of files and directories (POSIX, toybox)
  • cksum (host)
    Display file checksums and block counts (POSIX)
  • cksum (target)
    Display file checksums and block counts (POSIX, toybox)
  • clear
    Clear the screen (POSIX, toybox)
  • cmp
    Compare two files (POSIX, toybox)
  • cndfs
    Condense, restore, or mirror filesystems or disks
  • comm
    Select or reject lines common to two files (POSIX, toybox)
  • confstr
    Get or set a configuration string
  • coreinfo
    Display information about a core file
  • cp
    Copy files (POSIX, toybox)
  • cpio (host)
    Copy file archives in and out (UNIX)
  • cpio (target)
    Copy file archives into and out of a newc format cpio archive (POSIX, toybox)
  • crc32
    Output CRC-32 checksum for each file (POSIX, toybox)
  • cron
    Clock server (UNIX)
  • crontab
    Schedule periodic background work (POSIX)
  • cut
    Print selected fields of each line of a file to standard output (POSIX, toybox)
