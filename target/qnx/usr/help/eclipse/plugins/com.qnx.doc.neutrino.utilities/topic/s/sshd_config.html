/etc/ssh/sshd_config

OpenSSH SSH daemon configuration file

Name:

/etc/ssh/sshd_config

Description:

The sshd daemon reads configuration data from /etc/ssh/sshd_config (or the file specified with the -f option). For more information, see the OpenSSH documentation: https://man.openbsd.org/sshd_config
