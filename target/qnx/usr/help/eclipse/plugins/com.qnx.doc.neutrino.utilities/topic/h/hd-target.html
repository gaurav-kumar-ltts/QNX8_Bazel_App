hd (target)

Dump files in hexadecimal format (POSIX, toybox)

Syntax:

hexdump [-bCcdovx] [-n len] [-s skip] [file...]

Runs on:

QNX OS

Options:

-n len
Show len bytes of output.
-s skip
Skip bytes of input.
-v
Be verbose.
file
The pathname of an input file. If you don't specify any files, hd reads from standard input. If a file is a dash character (-), hd reads from the standard input at that point in the sequence.

Description:

The hd utility displays data in hexadecimal format. The name hd (hex dump) is derived from the default output format.

The display type options are as follows:
-b
One-byte octal display.
-C
Canonical display (hex and ASCII).
-c
One-byte character display.
-d
Two-byte decimal display.
-o
Two-byte octal display.
-x
Two-byte hexadecimal display (default).

This utility is provided as part of the toybox package. For information on how to enable it, see toybox.
