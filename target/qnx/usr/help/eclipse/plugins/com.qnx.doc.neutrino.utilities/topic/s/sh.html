sh

Public domain Korn shell command interpreter (UNIX)

Syntax:

sh [+-abCefhikmnprsuvxX] [+-o option]
   [ [ -c command-string [command-name] 
     | -s | file ] [argument ...] ]

Runs on:

QNX OS, Microsoft Windows

Options:

See ksh.

Description:

The sh shell is a public-domain version of the Korn shell. For more information, see ksh.

Note: You cannot rely on running DOS-type files in any kind of shell.
