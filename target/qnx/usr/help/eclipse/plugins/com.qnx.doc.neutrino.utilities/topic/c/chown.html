chown

Change the ownership of files and directories (POSIX, toybox)

Syntax:

chown [-HLPR] [-fhv] group file...

Runs on:

QNX OS

Options:

For a complete listing, see chgrp.

Description:

The chown utility changes the group of one or more files.

This utility is provided as part of the toybox package. For information on how to enable it, see toybox.

Contributing author:

Rob Landley and the toybox project (see https://landley.net/toybox/).
