arp

Address Resolution Protocol (ARP) display and control

Syntax:

arp [--libxo options] [-n] [-i interface] hostname
arp [--libxo options] [-n] [-i interface] -a
arp -d hostname [pub]
arp -d [-i interface] -a
arp -s hostname ether_addr [temp] [blackhole | reject] [pub]
arp -S hostname ether_addr [temp] [blackhole | reject] [pub]
arp -f filename

Runs on:

QNX OS

Description:

The arp utility that QNX OS provides is ported from FreeBSD.

For a detailed description, see the FreeBSD documentation (https://www.freebsd.org/cgi/man.cgi?query=arp&sektion=8&manpath=FreeBSD+13.4-RELEASE+and+Ports).
