ip6addrctl

Configure address selection policy for IPv6 and IPv4

Syntax:

ip6addrctl [show]
ip6addrctl add prefix precedence label
ip6addrctl delete prefix
ip6addrctl flush
ip6addrctl install configfile

Runs on:

QNX OS

Description:

The ip6addrctl utility that QNX OS provides is ported from FreeBSD.

For a detailed description, see the FreeBSD documentation (https://www.freebsd.org/cgi/man.cgi?query=ip6addrctl&sektion=8&manpath=FreeBSD+13.4-RELEASE+and+Ports).
