This chapter describes the utilities, etc. whose names start with U.

  • ubus_ctrl
    USB Bus State Enable/Disable utility
  • uesh
    Micro-embedded shell (QNX OS)
  • ulink_ctrl
    Control a USB DCD link
  • umask
    Get or set the file mode creation mask (POSIX)
  • umount
    Unmount a device
  • uname (host)
    Return the name of the operating system (POSIX)
  • uname (target)
    Print system information (POSIX, toybox)
  • uniq
    Report or filter out repeated lines in a file (POSIX, toybox)
  • unix2dos
    Convert newline format from Unix to DOS (POSIX, toybox)
  • unlink
    Call the unlink() function to delete a file
  • unxz, unlzma
    Decompress .xz and .lzma files
  • uptime
    Display the length of time that the system has been running
  • usb
    Display USB device configuration
  • use
    Print a usage message (QNX OS)
  • usemsg
    Change the usage message for a command (QNX OS)
  • uudecode
    Decode file from stdin (or infile) (POSIX, toybox)
  • uuencode
    Encode stdin (or infile) to stdout (POSIX, toybox)
  • uuidgen
    Create and print a new RFC4122 random UUID (POSIX, toybox)
