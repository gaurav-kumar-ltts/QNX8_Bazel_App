jls

List jails

Syntax:

jls [--libxo] [-dhNnqsv]	[-j jail] [parameter ...]

Runs on:

QNX OS

Description:

The jls utility that QNX OS provides is ported from FreeBSD.

For a detailed description, see the FreeBSD documentation (https://man.freebsd.org/cgi/man.cgi?query=jls&sektion=8&manpath=FreeBSD+13.4-RELEASE+and+Ports).
