qtdctl

QNX Trusted Disk (QTD) control utility

Syntax:

qtdctl -r path

Options:

-r path
Query the rollback information from a QTD-mounted partition path. The path can be the QTD partition itself or a filesystem mounted on the QTD partition.

Runs on:

QNX OS

Description:

The qtdctl utility allows you to interact with QNX Trusted Disk (QTD) partitions.

Examples:

Query the rollback version from the QTD-mounted disk partition path: 

qtdctl -r /dev/hd0t185-qnx6
version: 13 (0xd)

Query the rollback version from the QTD-protected filesystem mountpoint: 

qtdctl -r /system
version: 13 (0xd)
