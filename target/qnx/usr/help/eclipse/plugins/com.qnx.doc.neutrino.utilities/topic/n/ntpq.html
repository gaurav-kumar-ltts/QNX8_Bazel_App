ntpq

Monitor the NTP daemon and determine its performance

Syntax:

ntpq [-46dinp] [-c command] [host] [...]

Runs on:

QNX OS

Description:

The ntpq utility that QNX OS provides is from the Network Time Protocol (NTP) Project implementation of NTP.

For a detailed description, see the documentation the NTP Project provides (https://doc.ntp.org/documentation/4.2.8-series/ntpq/).
