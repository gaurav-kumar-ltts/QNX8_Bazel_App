pflog

Packet filter logging interface

Name:

pflog

Description:

The pflog interface is a device which makes visible all packets logged by the packet filter, pf.

For more information, see Packet Filtering in the High-Performance Networking Stack User's Guide, and the FreeBSD documentation (https://www.freebsd.org/cgi/man.cgi?query=pflog&sektion=4&manpath=FreeBSD+13.4-RELEASE+and+Ports).
