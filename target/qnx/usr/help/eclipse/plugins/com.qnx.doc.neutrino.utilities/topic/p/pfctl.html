pfctl

Control the packet filter (PF) and network address translation (NAT) device

Syntax:

pfctl [-AdeghMmNnOPqRrvz] [-a anchor] [-D macro=value] [-F modifier]
      [-f file] [-i interface] [-K host | network] [-k host | network |
      label | id | gateway] [-o level] [-p device] [-s modifier]
      [-t table -T command [address ...]] [-x level]

Runs on:

QNX OS

Description:

The pfctl utility that QNX OS provides is ported from FreeBSD.

For a detailed description, see the FreeBSD documentation (https://www.freebsd.org/cgi/man.cgi?query=pfctl&sektion=8&manpath=FreeBSD+13.4-RELEASE+and+Ports).
