sockstat

List the open sockets

Syntax:

sockstat [-46CciLlnqSsUuvw] [-p ports] [-P protocols]

Runs on:

QNX OS

Description:

The sockstat utility that QNX OS provides is ported from FreeBSD.

QNX OS does not support the -j option for sockstat.

For a detailed description, see the FreeBSD documentation (https://www.freebsd.org/cgi/man.cgi?query=sockstat&sektion=1&manpath=FreeBSD+13.4-RELEASE+and+Ports).
