vi

Visual interface editor clone (UNIX)

Syntax:

vi [options]... [+command] file...

Runs on:

QNX OS

Options:

See elvis for a full listing.

Description:

The vi utility is an interactive fullscreen editor that's compatible with the Unix/POSIX vi editor. The vi utility in the QNX OS is a link to elvis.

For more information, see Linda Lamb, Learning the vi Editor, O'Reilly and Associates, 1990.
