smmu_fini()

Terminate the client’s connection with smmuman

Synopsis:

#include <smmu.h>

void smmu_fini(void);

Library:

libsmmu.a

Description:

The smmu_fini() function terminates a client's connection with the smmuman service.

Warning: Before calling smmu_fini(), you must call smmu_obj_destroy() to destroy the SMMU object(s) to which your client has attached devices.
