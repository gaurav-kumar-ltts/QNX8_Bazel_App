misc.h

QNX helpers - Miscellaneous helpers.

  • QH_ARRAY_LENGTH
    Convenience macro that determines the length (number of elements) of an array.
  • qh_get_progname()
    Return the currently running program name without the path
  • qh_is_pwr_of_2_s8()
    Return whether the absolute value of an int8_t value is a power of two
  • qh_is_pwr_of_2_s16()
    Return whether the absolute value of an int16_t value is a power of two
  • qh_is_pwr_of_2_s32()
    Return whether the absolute value of an int32_t value is a power of two
  • qh_is_pwr_of_2_s64()
    Return whether the absolute value of an int64_t value is a power of two
  • qh_is_pwr_of_2_u8()
    Return whether a uint8_t value is a power of two
  • qh_is_pwr_of_2_u16()
    Return whether a uint16_t value is a power of two
  • qh_is_pwr_of_2_u32()
    Return whether a uint32_t value is a power of two
  • qh_is_pwr_of_2_u64()
    Return whether a uint64_t value is a power of two
  • QH_UNUSED
    Convenience macro that marks a variable as unused to prevent compiler warnings.
