log.h

QNX helpers related to logging.

All QNX helpers logging functions are thread safe.

  • Setting up QNX helpers logging
    QNX helpers logging provides default settings and configuration that initialize slog2.
  • Controlling QNX helpers logging
    Logging using QNX helpers is controlled by a configuration string that specifies a combination of the destination flags, the verbosity of a context, and the message-specific flags.
  • Macros
    These macros are the preferred method for making log calls. They are simplified versions of the QNX helpers logging functions.
  • Macro variables
    These macro definitions are used with QNX helpers logging macros and functions.
  • qh_log_check()
    Check whether a message with the given log information structure is logged
  • qh_log_context_create()
    Create a logging context
  • qh_log_context_destroy()
    Destroys a logging context
  • qh_log_context_normalize_name()
    Normalize a context name
  • qh_log_context_t
    The opaque context type used by QNX helpers logging functions
  • qh_log_ex()
    Log a formatted message
  • qh_log_get_destinations()
    Get the destinations a specified context uses
  • qh_log_get_destinations_by_name()
    Get logging destinations based on a context name
  • qh_log_get_verbosity()
    Get the verbosity for the specified combination of context and destinations
  • qh_log_get_verbosity_by_name()
    Get the verbosity for the specified combination of named context and destinations
  • qh_log_info_t
    The information structure used with QNX helpers logging functions
  • qh_log_set_cl_mode()
    Set the logging configuration to command line mode
  • qh_log_update_config()
    Update the logging configuration based on a configuration string
  • qh_log_verbosity_to_str()
    Get the string representation of the specified verbosity
  • qh_vlog_ex()
    Log a formatted message using a variable-argument list
