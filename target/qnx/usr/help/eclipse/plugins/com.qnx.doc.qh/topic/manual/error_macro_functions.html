Macros

These macros are related to errno handling.

  • QH_ABORT()
    Convenience macro that logs an error message using a QNX helpers function and then calls abort()
  • QH_ABORT_ON_ERRNO()
    A convenience macro that allows you to call qh_abort_on_errno() without specifying qh_log_info
  • QH_RET_ERRNO()
    A macro that sets errno and returns its value
  • QH_SET_ERRNO()
    A macro that sets errno
  • QH_RET_ERRNO_WEOK()
    A macro that conditionally sets errno and always returns the specified error
  • QH_RET_ON_ERRNO()
    A macro that conditionally (if not EOK) sets errno and returns the specified error
