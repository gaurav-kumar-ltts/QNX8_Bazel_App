time.h

QNX helpers - Helpers related to time.

  • Sleep time and absolute time
  • Unit conversion definitions
    All these definitions are in uint64_t.
  • qh_get_nstime()
    Gets the (adjusted) time from the clock with the specified ID, in nanoseconds
  • qh_nssleep()
    Sleep for a specified amount of time, trying not to exceed a specified absolute time
  • qh_poll_check_cb_ft
    Prototype for a callback function that provides the results of a poll check
  • qh_poll_until()
    Call the specified poll check function at a specified interval
