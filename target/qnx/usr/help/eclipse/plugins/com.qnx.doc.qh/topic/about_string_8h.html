string.h

QNX helpers - Helpers related to strings and string conversions.

  • Macros
    These macros make a string from a passed-in argument name or value.
  • qh_malloc_sprintf()
    Print formatted output into a newly allocated string
  • qh_memclear()
    Set the memory to zero
  • qh_str()
    Return a specified string, a fallback string if the specified string is NULL, or an empty string if the fallback string is also NULL
  • qh_str_groupname_to_gid()
    Safely converts a string into a gid_t
  • qh_str_to_bool()
    Safely converts a string into a boolean
  • qh_str_to_bytes()
    Safely converts a string representing a size in bytes with an optional size suffix into a uint64_t
  • qh_str_to_char()
    Safely converts a string into a char
  • qh_str_to_errno()
    Safely converts a string that represents an errno symbol or number into its corresponding errno value (an int)
  • qh_str_to_int()
    Safely converts a string into an int
  • qh_str_to_int8()
    Safely converts a string into an int8_t
  • qh_str_to_int16()
    Safely converts a string into an int16_t
  • qh_str_to_int32()
    Safely converts a string into an int32_t
  • qh_str_to_int64()
    Safely converts a string into an int64_t
  • qh_str_to_long()
    Safely converts a string into a long
  • qh_str_to_llong()
    Safely converts a string into a llong
  • qh_str_to_mode()
    Safely converts a string into a mode_t
  • qh_str_to_schar()
    Safely converts a string into a signed char
  • qh_str_to_signal()
    Safely converts a string that represents a signal name or number into an int
  • qh_str_to_size()
    Safely converts a string into a size_t
  • qh_str_to_ssize()
    Safely converts a string into a ssize_t
  • qh_str_to_uchar()
    Safely converts a string into an unsigned char
  • qh_str_to_uint()
    Safely converts a string into an unsigned int
  • qh_str_to_uint8()
    Safely converts a string into a uint8_t
  • qh_str_to_uint16()
    Safely converts a string into a uint16_t
  • qh_str_to_uint32()
    Safely converts a string into a uint32_t
  • qh_str_to_uint64()
    Safely converts a string into a uint64_t
  • qh_str_to_ullong()
    Safely converts a string into an unsigned long long
  • qh_str_to_ulong()
    Safely converts a string into an unsigned long
  • qh_str_username_to_uid()
    Safely converts a string into a uid_t
  • qh_strcmp()
    Safely compare two strings
  • qh_strdup()
    Safely create a duplicate of a string
