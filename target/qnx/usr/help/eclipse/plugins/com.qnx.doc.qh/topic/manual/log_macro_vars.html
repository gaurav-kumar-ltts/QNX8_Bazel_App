Macro variables

These macro definitions are used with QNX helpers logging macros and functions.

  • Set of log destinations or no log destinations
    Identifiers that represent either a set of log destinations or no destinations.
  • Blocked destinations
    Log flags that represent a log message destination that is blocked.
  • Flags for converting destinations
    The size of the shift for converting from *_DEST_* defines and masks to *_NO_DEST_* ones, and vice versa.
  • Log message output
    Optional flags used in a qh_log_*() call that modify the log message output.
  • Log to stderr based on log level
    These convenience flags combine a log level and the stderr destination.
  • Log to stderr or stdout based on log level
    These convenience flags combine a log level and the stdout and stderr destinations.
  • Message destinations
    Log flags that specify log message destinations.
  • Message with severity
    Convenience logging macros that implicitly specify the logging severity that is normally specified when calling the qh_log() or qh_log_noloc() macros.
  • QH_LOG_USER_CONTEXT_VAR
    A variable that holds the name of the user QNX helpers logging context.
  • Severity level masks
    A set of masks that represent the different sections of the severity level.
  • User-reserved area
    A mask and shift size that represent the area of the flags that is reserved for users.
  • Verbosity levels
    Identifiers that represent the verbosity levels when logging messages.
  • Version numbers
