qh_set_errno()

Set errno

Synopsis:

#include <qh/error.h>
static errno_t qh_set_errno(const errno_t errval)

Arguments:

errval
The standard errno to set errno to.

Library:

qh

Description:

This function sets errno to the error value specified by errval and returns the value of errval.

Returns:

The value of errval.
