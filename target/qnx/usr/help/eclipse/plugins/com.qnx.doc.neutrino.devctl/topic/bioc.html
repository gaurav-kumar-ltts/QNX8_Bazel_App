BIOC*

QNX OS provides extensions to Berkeley Packet Filtering (BPF) ioctl() commands to support sending multiple packets in one API call. For more information on using this feature, go to the bpf entry in the QNX OS Utilities Reference.

For additional ioctl() command codes, go to the FreeBSD documentation (https://www.freebsd.org/cgi/man.cgi?query=bpf&sektion=4&manpath=FreeBSD+13.4-RELEASE+and+Ports).

For more information on QNX OS packet filtering, go to Packet Filtering in the High-Performance Networking Stack User's Guide.
