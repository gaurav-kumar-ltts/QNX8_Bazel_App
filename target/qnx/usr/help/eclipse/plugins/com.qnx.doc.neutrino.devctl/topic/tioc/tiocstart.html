TIOCSTART

Start output

Synopsis:

#include <sys/ioctl.h>

#define TIOCSTART       _IO('t',  110)

Arguments to ioctl():

Argument Value
fd A file descriptor that you obtained by opening the device
request TIOCSTART

Description:

This command starts output. It's like pressing CtrlQ.

Input:

None.

Output:

None.
