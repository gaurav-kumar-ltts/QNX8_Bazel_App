DCMD_DUMPER_*

This chapter describes the commands that apply to postmortem dumps and the dumperdevctl() utility.

  • DCMD_DUMPER_GETPATH
    Get the path of the dump file associated with a process ID
  • DCMD_DUMPER_NOTIFYEVENT
    Register for dump notifications
  • DCMD_DUMPER_REMOVEEVENT
    Remove a notification event
