PTP_GET_TIME

Get the current PTP time

Synopsis

#include <io-sock/ptp.h>

#define PTP_GET_TIME		0x102

Arguments to @e ioctl():

Argument Value
@v fd File descriptor obtained by opening the device
@v request SIOCGDRVSPEC
Additional argument A pointer to an ifdrv

Description

This command gets the current time as calculated by the PTP module.

Input

A filled-in ifdrv, defined in @f net/if.h.

struct ifdrv {
	char		ifd_name[IFNAMSIZ];
	unsigned long	ifd_cmd;
	size_t		ifd_len;
	void		*ifd_data;
};

Fill in each member using the following information:

  • ifd_name: The interface name; e.g., en0
  • ifd_cmd: PTP_GET_TIME
  • ifd_len: The size of a ptp_time structure
  • ifd_data: A pointer to a ptp_time structure

Output

The ptp_time structure pointed to by ifd_data is filled in with the current time.
