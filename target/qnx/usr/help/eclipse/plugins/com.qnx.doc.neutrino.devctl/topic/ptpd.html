DCMD_PTPD_*

This chapter describes the devctl() commands that apply to the Precision Time Protocol (PTP) daemon, ptpd2. If you specify the -K option, ptpd2 registers /dev/ptpd (DEFAULT_PTPD_PATH, defined in <dcmd_ptpd.h>) in the path namespace; use these commands with a file descriptor from opening this path.

  • DCMD_PTPD_DELAYMS
    Get the master-to-slave delay
  • DCMD_PTPD_DELAYSM
    Get the slave-to-master delay
  • DCMD_PTPD_GET_PDELAY_INTERVAL
    Get the pdelay interval
  • DCMD_PTPD_GET_TAI_UTC_OFFSET
    Get the offset from TAI to UTC
  • DCMD_PTPD_GET_TIME
    Get the current time
  • DCMD_PTPD_INFO
    Get the peer delay and neighbor rate ratio
  • DCMD_PTPD_SEND_SIGNALING_MSG
    Send a signaling message
  • DCMD_PTPD_SET_PDELAY_INTERVAL
    Set the pdelay interval
  • DCMD_PTPD_STATUS
    Get the error status for the Precision Time Protocol
