DCMD_MMCSD_*

This chapter describes the devctl() commands that apply to MultiMedia Card/Secure Digital. This is the older framework for these cards; see also the DCMD_SDMMC_* commands.

Note: The DCMD_MMCSD_GET_ECCERR_ADDR command isn't implemented.
  • DCMD_MMCSD_CARD_REGISTER
    Read a card register
  • DCMD_MMCSD_ERASE
    Erase an area on the device
  • DCMD_MMCSD_ERASED_VAL
    Get an erased value
  • DCMD_MMCSD_GET_CID
    Get card ID information
  • DCMD_MMCSD_GET_CID_RAW
    Get raw card ID information
  • DCMD_MMCSD_GET_CSD
    Get card-specific data
  • DCMD_MMCSD_RPMB_RW_FRAME
    Read or write an RPMB frame
  • DCMD_MMCSD_RPMB_SIZE
    Get the size of the RPMB partition
  • DCMD_MMCSD_VUC_CMD
    Execute a vendor-unique command
  • DCMD_MMCSD_WRITE_PROTECT
    Clear or set write protection
