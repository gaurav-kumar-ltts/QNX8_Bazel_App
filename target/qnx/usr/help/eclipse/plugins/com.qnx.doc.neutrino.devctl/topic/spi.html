DCMD_SPI_*

This chapter describes devctl() commands that apply to the SPI (Serial Perphiral Interface) framework.

For more information, refer to the following documents:
  • SPI (Serial Peripheral Interface) Framework Technotes
  • devctl() in the QNX OS C Library Reference
  • DCMD_SPI_DATA_XCHNG
    Performs a symmetrical data exchange between a specific device and the client application
  • DCMD_SPI_GET_DEVINFO
    Get the SPI device information
  • DCMD_SPI_GET_DRVINFO
    Get the SPI driver information
  • DCMD_SPI_SET_CONFIG
    Set the SPI device configuration
