CAN_DEVCTL_*

This chapter describes the devctl() commands that apply to Controller Area Networks and the dev-can-* drivers.

These commands are used in Board Support Packages for targets that support CAN, and the details of some commands depend on the board; you can find additional information in src/hardware/can/board_name/board_namecan.readme in your BSP. The canctl utility provides a command-line interface to the CAN_DEVCTL_* commands.

You need to use some commands with the file descriptor for a specific receive or transmit mailbox (e.g., /dev/can1/tx3).

  • CAN_DEVCTL_DEBUG_INFO
    Get debugging information
  • CAN_DEVCTL_DEBUG_INFO2
    Get specific debugging information
  • CAN_DEVCTL_ERROR
    Get error information
  • CAN_DEVCTL_GET_INFO
    Get information about the CAN configuration
  • CAN_DEVCTL_GET_MFILTER
    Get the current message filter
  • CAN_DEVCTL_GET_MID
    Get a message ID
  • CAN_DEVCTL_GET_PRIO
    Get the priority for transmitted messages
  • CAN_DEVCTL_GET_STATS
    Get CAN statistics
  • CAN_DEVCTL_GET_TIMESTAMP
    Get the device timestamp
  • CAN_DEVCTL_READ_CANMSG_EXT
    Read an extended CAN message
  • CAN_DEVCTL_RX_FRAME_RAW_BLOCK
    Get a message in raw frame mode (blocking)
  • CAN_DEVCTL_RX_FRAME_RAW_NOBLOCK
    Get a message in raw frame mode (nonblocking)
  • CAN_DEVCTL_SET_MFILTER
    Set the message filter
  • CAN_DEVCTL_SET_MID
    Set the message ID
  • CAN_DEVCTL_SET_PRIO
    Set the priority for transmitted messages
  • CAN_DEVCTL_SET_TIMESTAMP
    Set the device timestamp
  • CAN_DEVCTL_SET_TIMING
    Set the reference clock frequency and bit timings
  • CAN_DEVCTL_TX_FRAME_RAW
    Transmit a message in raw frame mode
  • CAN_DEVCTL_WRITE_CANMSG_EXT
    Write an extended CAN message
