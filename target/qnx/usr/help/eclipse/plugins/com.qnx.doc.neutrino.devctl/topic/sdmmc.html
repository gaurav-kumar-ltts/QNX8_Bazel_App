DCMD_SDMMC_*

This chapter describes the devctl() commands that apply to Secure Digital/MultiMedia Card. This is the newer framework for these cards; see also the DCMD_MMCSD_* commands.

  • DCMD_SDMMC_ASSD_APDU
    Transfer an APDU packet to the device
  • DCMD_SDMMC_ASSD_CONTROL
    Control an Advanced Security SD card operation
  • DCMD_SDMMC_ASSD_PROPERTIES
    Get Advanced Security SD card properties
  • DCMD_SDMMC_ASSD_STATUS
    Get the status of an Advanced Security SD card operation
  • DCMD_SDMMC_CARD_REGISTER
    Read or write a card register
  • DCMD_SDMMC_DEVICE_HEALTH
    Get information about the device's health
  • DCMD_SDMMC_DEVICE_INFO
    Get information about the device
  • DCMD_SDMMC_ERASE
    Erase the device
  • DCMD_SDMMC_GEN_CMD
    Send a general command to the device
  • DCMD_SDMMC_LOCK_UNLOCK
    Lock or unlock the device
  • DCMD_SDMMC_MAN_CMD
    Send a manufacturer command to the device
  • DCMD_SDMMC_PART_INFO
    Get or clear information about a partition
  • DCMD_SDMMC_PWR_MGNT
    Control power management for the device
  • DCMD_SDMMC_WRITE_PROTECT
    Clear or set write protection
