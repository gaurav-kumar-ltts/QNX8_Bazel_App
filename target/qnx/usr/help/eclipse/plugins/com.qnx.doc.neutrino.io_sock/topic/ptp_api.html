PTP Module Library API

These PTP module functions are implemented by the PTP module. Networking drivers use them to handle actions such as transmit (Tx) and receive (Rx) timestamping and handing off PTP I/O-command (ioctl()) command processing.

For information on using these functions, including examples, go to Adding PTP to io-sock Network Drivers.

  • Memory buffer tag (m_tag) macros
    Memory buffer (mbuf) tag macros, for use with ptp_tstmp_locate().
  • PTP header comparison macros
    A set of macros to compare two ptp_uhdr structures.
  • ptp_attach()
    Attach device to use ptp_*() functions and allocate the context structure
  • ptp_counter_to_realtime()
    Calculate the current time from the PTP time counter and the driver time
  • ptp_detach()
    Detach and disable the device's PTP context
  • ptp_hdr2uhdr()
    Copy header information retrieved from the memory buffer to a PTP header
  • ptp_ioctl()
    Process SIOCGDRVSPEC and SIOCSDRVSPEC I/O-control commands to service ptp_()* commands
  • ptp_mbuf2hdr()
    Returns a pointer to a PTP header in a memory buffer
  • ptp_read_time()
    Read the current time from driver and PTP module information
  • ptp_rx()
    Return a packet's receive (Rx) timestamp
  • ptp_tstmp_locate()
    Return a pointer to a memory buffer tag's ptp_tstmp structure
  • PTP_TX_TIMESTAMP()
    Comparison macro to check if Tx timestamp initialization is needed
  • ptp_txfinish()
    Return a packet's Tx timestamp
  • ptp_txintr()
    Return a packet's Tx timestamp without associating it with a memory buffer (mbuf)
  • ptp_txintr_finish()
    Return a packet's Tx timestamp when the timestamp has been received
  • ptp_txintr_finish_head()
    Return a packet's Tx timestamp when the timestamp has been received
  • ptp_uhdr
    A structure to hold fields that identify a PTP packet
