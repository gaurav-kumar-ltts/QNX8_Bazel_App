WiFi capability

The QNX OS Wi-Fi resources that work with io-sock include the wpa_cli, wpa_supplicant, wpa_passphrase, hostapad, and hostapad_cli utilities. For information on how to use them, see the Utilities Reference. (See Networking Utilities for a full list of networking resources.)

In addition to supporting native FreeBSD WiFi drivers, io-sock supports a driver for Synaptics DHD PCIE-based WLAN devices (see the devs-qwdi_dhd_syn_pcie-version.so entry in the Utilities Reference).
