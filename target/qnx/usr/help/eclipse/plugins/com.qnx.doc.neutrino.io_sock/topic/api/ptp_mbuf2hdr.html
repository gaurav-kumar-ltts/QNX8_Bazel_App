ptp_mbuf2hdr()

Returns a pointer to a PTP header in a memory buffer

Synopsis:

#include <qnx/ptp/ptp_mod.h>
struct ptp_hdr* ptp_mbuf2hdr(struct mbuf *m)

Arguments:

m
The mbuf containing the packet. The M_PKTHDR flag must be set.

Library:

ptp

Description:

Currently supports IPv4 and L2. Packet is assumed to be in one mbuf (i.e., no m_next).

Returns:

If successful, returns a pointer to the PTP header in an mbuf; otherwise, one of the following:
  • NULL - Invalid type or length in the provided mbuf.
