a Our internal representation for filenames is UTF-8, which has a variable number of bytes per character. Many on-disk formats instead use UCS2, which is a fixed number (2 bytes). Thus a length limit in characters may be 1, 2, or 3 times that number in bytes, as we convert from on-disk to OS representation. The lengths for the Power-Safe and EXT2 filesystems are in bytes; those for UDF and DOS/VFAT are in characters.
b The RAM filesystem (/dev/shmem) isn't really a filesystem; it's a window onto the shared memory names that has some filesystem-like characteristics. See Builtin RAM disk later in this chapter.
c VFAT or FAT32 (Windows 95 or later).
d 255-character filename lengths used by VFAT or FAT32 (e.g., Windows 95).
e Limited by the remote filesystem.
f The Squash filesystem contains a single timestamp (the modification time of the original source file) that is advertised as the access, modification, and status change timestamps.
