Relative pathnames

Pathnames need not start with slash. In such cases, the path is considered relative to the current working directory.

The OS maintains the current working directory as a character string. Relative pathnames are always converted to absolute pathnames (i.e. a pathname that starts with a leading slash) by prepending the current working directory string to the relative pathname.
