Networking abilities

If your system controls permissions for networking operations using process manager (procmgr) abilities that are set using procmgr_ability(), QNX recommends that you instead generate and apply a security policy that controls abilities (for information, go to the Security Policies chapter of the QNX OS System Security guide). This method helps ensure that io-sock and client processes have the abilities they need to perform networking operations.

If you do not use a security policy, to control io-sock abilities, QNX recommends that you use the sysctl variable qnx.sec.droproot to run io-sock with the abilities for a specified user (for more information, go to the sysctl entry in the QNX OS Utilities Reference).
