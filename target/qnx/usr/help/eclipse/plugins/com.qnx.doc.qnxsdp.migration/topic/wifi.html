WiFi

QNX SDP 8.0 provides the driver devs-qwdi_syn_dhd_pcie-2_10.so, which is for Synaptics DHD PCIE-based WLAN devices. It supports the new WiFi chipset BCM43752, and, as its name suggests, the 2.10 version of QNX Wi-Fi Driver Integration (QWDI).

For more information, go to the devs-qwdi_syn_pcie-version.so entry in the Utilities Reference.

The supported option and configuration for the Wi-Fi Protected Access (WPA) client and IEEE 802.1X supplicant have not changes for QNX SDP 8.0. Go to the wpa_supplicant-version entry in the Utilities Reference.
