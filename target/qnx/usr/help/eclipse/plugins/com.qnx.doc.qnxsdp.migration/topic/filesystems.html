Filesystems

Filesystem ownership and permissions

The mntperms option (used with devb-* drivers as a command-line option and mount -o) has been removed. Use the following options instead:
  • For filesystems that do not have real POSIX permissions (FAT, QTD, partitions, and block devices): the attributes dperms=, fperms=, perms=, uid=, gid=.
  • For filesystems with a real root directory (qnx6fs, ext2fs, qcfs, squashfs), the correct way to control the permission of the mountpoint is to control the permission of the / (root) directory in the buildfile, or via the command: chmod mountpoint
