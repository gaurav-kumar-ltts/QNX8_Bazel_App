Networking

The High-Performance Networking Stack (io-sock) was introduced for QNX SDP 7.1 as a replacement for the io-pkt networking stack and is updated for QNX SDP 8.0.

In addition to the following sections on networking migration, see the networking-specific content in the Buildfiles section of the Board Support Packages chapter.

  • Modifying a BSP to support io-sock
    If QNX does not provide a BSP that supports io-sock for your target hardware, you need to create one. To simplify the process, QNX recommends that you start with the io-sock-compatible BSP provided by QNX that most closely matches your target's specifications.
  • Migrating from QNX SDP 7.1 io-pkt to QNX SDP 8.0 io-sock
