Toolchain

QNX SDP 8.0 provides support for the GCC 12.x toolchain.

In GCC 12.2, a number of constructions that generated warning messages in previous releases now generate errors that cannot be suppressed.

See the GCC documentation for information on porting projects to newer versions of GCC:

  • https://gcc.gnu.org/gcc-9/porting_to.html
  • https://gcc.gnu.org/gcc-10/porting_to.html
  • https://gcc.gnu.org/gcc-11/porting_to.html
  • https://gcc.gnu.org/gcc-12/porting_to.html
