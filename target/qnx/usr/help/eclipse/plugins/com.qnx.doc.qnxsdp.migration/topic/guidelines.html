Migration Guidelines

This chapter provides tips for specific aspects of moving to the current version of QNX SDP.

  • Kernel and process manager
  • Networking
    The High-Performance Networking Stack (io-sock) was introduced for QNX SDP 7.1 as a replacement for the io-pkt networking stack and is updated for QNX SDP 8.0.
  • Filesystems
  • Toolchain
  • Target-side command-line utilities
  • Security
  • Graphics and Screen
  • Audio
  • WiFi
  • C and C++ applications
  • mkqnximage virtual machine image generator
  • Board Support Packages
    Updating a BSP for QNX SDP 7.1 to build and work in the QNX SDP 8.0 environment requires changes to the buildfile and drivers.
  • QNX Momentics IDE
    For a complete list of new and discontinued features that may affect your IDE projects, go to the QNX Momentics IDE 8.0 release notes and the QNX Software Development Platform 8.0: Discontinuation and Deprecation Notice.
