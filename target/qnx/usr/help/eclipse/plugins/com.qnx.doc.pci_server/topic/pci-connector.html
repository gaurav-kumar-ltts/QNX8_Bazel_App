Command line for PCI connector (pci-connector)

Connect PCI multiplexer APIs to the PCI server

Syntax:

pci-connector [-n name] [-s instance] [-v]

Runs on:

QNX OS

Options:

-n name
The name of the resource manager connector.
-s instance
The pci-server instance to connect to.
-v
Be verbose.

Description:

The PCI connector (pci-connector) is a resource manager process that mediates communication between a client and a pci-server instance.

Each client can have one or more connectors. You can attach multiple connectors from different clients to the same PCI server simultaneously. The PCI connectors have a:

  • N:1 relationship with a PCI server, where N is the number of PCI connectors.
  • 1:1 relationship with a client via direct connect.
  • 1:M relationship with clients in a multiplexed scenario.
